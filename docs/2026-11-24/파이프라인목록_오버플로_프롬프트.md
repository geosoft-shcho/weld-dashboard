# 파이프라인 목록 RenderFlex 오버플로 수정

## 목표
적재 파이프라인 하단 목록이 좁은 폭(약 137px)에서도 Row가 가로로 넘치지 않고, 패널 높이 안에서 하단 병목 블록이 세로로 넘치지 않게 한다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md`
3. `lib/src/presentation/features/collection_monitoring/widgets/pipeline_trace_list.dart`
4. `lib/src/presentation/features/collection_monitoring/widgets/pipeline_trace_tab_body.dart`
5. 계약·화면안: 없음

## 현재 상태
- `pipeline_trace_list.dart` 105행 `Row`: `›`·점·고정폭(36+52+40)+간격이 Expanded보다 먼저 자리를 먹어, 가용 폭 137px에서 약 18px 가로 오버플로.
- `pipeline_trace_tab_body.dart` `_TraceListPanel`: 고정 `SizedBox(height: listHeight)` Column 안에 헤더·목록·선택 요약·큐 병목이 함께 있어, 병목 패널이 크면 세로 오버플로가 난다.

## 바꿀 것
1. 목록 행: 고정폭 텍스트 칸을 `Flexible`/`Expanded`+ellipsis로 바꿔 좁은 폭에서 줄인다. 접두(`›`, 상태 점)만 고정.
2. 목록 패널: 선택 요약·큐 병목을 `Flexible`+스크롤(또는 maxHeight)로 가둬 세로 오버플로를 막는다.

## 유지할 것
- 목록 데이터·선택·필터·펄스 애니메이션 동작.
- 그래프 뷰·칩 UI(이번 범위에서 손대지 않음 — 별도 오버플로면 후속).

## 이번 작업에서 만들지 않음
- 파이프라인 그래프/칩 레이아웃 전면 개편.
- 새 디자인 시스템·카드.

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
