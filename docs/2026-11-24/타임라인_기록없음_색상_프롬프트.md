# 타임라인 기록 없음 색상

## 목표
「기록 없음」 막대·점이 어두운 타임라인에서 잘 보이도록, 회색(`STATUS_OFF`) 대신 기존 테마의 경고색(`STATUS_WARN`)을 쓴다. 범례·막대 색을 맞춘다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md`
3. `lib/src/presentation/core/themes/app_theme.dart`
4. `lib/src/presentation/features/collection_monitoring/widgets/collection_timeline_host.dart`
5. `lib/src/presentation/features/collection_monitoring/widgets/collection_event_timeline_mapper.dart`
6. `lib/src/presentation/features/collection_monitoring/widgets/timeline_status_style.dart`
7. 계약·화면안: 없음

## 현재 상태
- 기록 없음(`disconnected`) 색이 `AppTheme.STATUS_OFF`(회색)라 배경·수집(초록) 대비가 약하다.

## 바꿀 것
1. 범례「기록 없음」색을 `STATUS_WARN`으로.
2. `colorOf`에서 disconnected/error(타임라인 비수집)를 `STATUS_WARN`으로.
3. `TimelineStatusStyle.of`에서 비수집 색을 `STATUS_WARN`으로.
4. 판정 로직·라벨·범례 항목 구성은 유지.

## 유지할 것
- API summary·asset 기반 수집/기록 없음 판정
- 수집 = `STATUS_OK`
- KPI 등 다른 화면의 `STATUS_OFF` 사용

## 이번 작업에서 만들지 않음
- 새 테마 색 상수 추가
- ConnectionStatus enum 변경

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
