# 긴 공사명(동원글로벌…) 리소스 타임라인 표시 개선

## 목표
`동원글로벌터미널부산 컨테이너크레인 제작설치 공사`처럼 라벨이 긴 공사·노드가 리소스 타임라인·공사 필터에서 이름을 반복·넘치지 않게 보이고, 점(◆) 막대는 시각 라벨만 보여 사용자가 구간을 읽기 쉽게 한다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md` (가이드라인 저장소는 워킹 트리 밖에서 읽기만)
3. `lib/src/domain/use_cases/present_collection_nodes_use_case.dart`
4. `lib/src/presentation/features/collection_monitoring/widgets/collection_resource_timeline_view.dart`
5. `lib/src/presentation/features/collection_monitoring/widgets/collection_event_timeline_mapper.dart`
6. `lib/src/presentation/features/collection_monitoring/widgets/collection_command_bar.dart`
7. 계약·화면안: 없음

## 현재 상태
- `present_collection_nodes_use_case.dart`: 이벤트 `windowLabel`이 노드 `firstRecordedAt`/`lastRecordedAt`(없으면 `node.label`)이라, 시각이 없으면 점 막대에 긴 공사명이 그대로 붙고, segment별 시각이 아니다.
- `collection_resource_timeline_view.dart`: 행 라벨 `maxLines: 2`, `TextOverflow.visible`이라 긴 이름이 열(약 220px)을 넘기기 쉽고, 점 막대는 `◆ ${event.windowLabel}`이다.
- `collection_event_timeline_mapper.dart`: `semanticLabel`이 `equipmentName` + `windowLabel`이라 둘 다 이름이면 접근성 문구가 이름을 반복한다.
- `collection_command_bar.dart`: 공사/품목/작업 ComboBox 항목이 긴 라벨을 말줄임 없이 둔다.
- Chrome(2026-10-26): 동원 공사에 ◆가 다수 보이며, 접근성 라벨이 공사명을 여러 번 반복하는 경우가 있었다.

## 권장안 (채택)
1. **점·구간 windowLabel**: 해당 segment의 `startedAt`/`endedAt`으로 만든다. 점은 `MM/dd HH:mm`(또는 동일일 시 `HH:mm`이 아니라 기존 `_dateClock`/`_clock` 규칙에 맞춤). 시각이 있는 segment는 `node.label`을 windowLabel로 쓰지 않는다.
2. **막대 문구**: 점은 `◆` + windowLabel(시각). windowLabel이 비거나 `equipmentName`과 같으면 `◆`만.
3. **행 라벨**: 2줄 ellipsis + Tooltip(전체 라벨).
4. **필터 ComboBox**: 항목/표시 텍스트 1줄 ellipsis.
5. **semanticLabel**: 점이면 `{이름} 점 {windowLabel}` 유지하되, windowLabel이 이름과 같으면 `{이름} 점`만.

동일 로직이 `remote_collection_catalog_repository.dart`의 `_windowLabel`/`_eventsFrom`에도 있으면 같은 규칙으로 맞춘다.

## 바꿀 것
1. `present_collection_nodes_use_case.dart` — 이벤트 windowLabel을 segment 시각 기준으로 생성.
2. `collection_resource_timeline_view.dart` — 행 Tooltip+ellipsis, 점 막대 중복 이름 제거.
3. `collection_event_timeline_mapper.dart` — semanticLabel·presentation title에서 이름 중복 방지.
4. `collection_command_bar.dart` — 레벨 ComboBox 라벨 ellipsis.
5. (해당 시) `remote_collection_catalog_repository.dart` — 이벤트 windowLabel 동일 규칙.
