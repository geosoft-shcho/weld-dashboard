# mediatag proto 2026-10-12 (기준 커밋 9cc36c1)

바뀐 파일은 `mediatag/compose/v1/compose.proto` 하나다. 모두 추가라 기존 호출은 그대로 된다.
운영 서버(`118.221.119.113:33210`)에 적용돼 있다.

## 1. GetClip (새 RPC)

클립 하나를 번호로 읽는다. 없는 번호는 `NOT_FOUND`.

- 요청: `{"clipId": "17226", "includeAssets": true}`
- 응답: `clip`, 그리고 `includeAssets`가 true면 `asset`(클립의 `source`가 가리키는 Asset 메타 — `source`가 없는 tag·relation 클립이면 비어 있다)

## 2. ClipProvenance.target_kind · target_id (새 칸, 읽기 전용)

도구가 만든 클립이 무엇을 대상으로 돌린 실행에서 나왔는지다(`ToolRun.target`과 같은 값). `GetClip`·`GetTimeline` 등 클립이 나오는 모든 응답에 실린다.

| `targetKind` | `targetId`의 뜻 |
|---|---|
| `CLIP_TARGET_KIND_CLIP` | 대상 클립의 `clip_id` |
| `CLIP_TARGET_KIND_ASSET` | 대상 파일의 `asset_id` |
| `CLIP_TARGET_KIND_UNSPECIFIED`(칸 없음) | 대상이 지워짐 |

번호는 종류마다 따로 세므로 `targetKind`를 먼저 보고 `targetId`를 쓴다.

예: `"provenance": {"runId": "96", "toolId": "6", "toolVersion": "1.0.0", "targetKind": "CLIP_TARGET_KIND_CLIP", "targetId": "9247"}`

자세한 사용법은 같이 든 `프론트 proto 공유 안내.md`.
