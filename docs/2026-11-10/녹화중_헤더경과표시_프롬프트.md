# 녹화 중 경과 시간 헤더 표시

## 목표
녹화 중 경과 문구(`● 녹화 중  …`)를 미리보기 아래가 아니라 타이틀 바(헤더)에 두어, 패널을 축소해도 녹화 중임을 알 수 있게 한다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md`
3. `lib/src/presentation/features/video_multimodal/widgets/camera_recording_dialog.dart`
4. 계약·화면안: 없음

## 현재 상태
- 경과 문구는 `!isMinimized` 본문(미리보기 아래)에만 있어 축소 시 보이지 않는다.
- 헤더는 `카메라 녹화` 제목과 최소화·닫기만 있다.

## 바꿀 것
1. `camera_recording_dialog.dart` 헤더 Row에서, `recordingElapsedLabel`이 비어 있지 않으면 제목 옆에(또는 제목 자리에 이어서) `● 녹화 중  {elapsed}`를 빨간 강조로 표시한다. 축소·펼침 모두 헤더는 보이므로 항상 표시된다.
2. 본문(미리보기 아래)의 동일 경과 문구 블록은 제거한다.
3. ViewModel·타이머 로직은 바꾸지 않는다.

## 유지할 것
- 드래그·최소화·닫기·미리보기·버튼 흐름
- `recordingElapsedLabel` getter 의미

## 이번 작업에서 만들지 않음
- 새 위젯 파일·디자인 시스템
- 헤더 높이·패널 폭 변경(말줄임으로 수용)

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
