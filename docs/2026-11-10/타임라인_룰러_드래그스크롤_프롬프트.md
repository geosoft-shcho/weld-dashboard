# 타임라인 룰러를 드래그해 가로 스크롤한다

## 목표
룰러를 마우스로 드래그하면 타임라인이 가로로 스크롤(패닝)되고, 짧게 누르면 기존처럼 시크된다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md` (가이드라인 저장소는 워킹 트리 밖에서 읽기만)
3. `lib/src/presentation/features/video_multimodal/widgets/multimodal_timeline_board.dart` (`_ruler`, `_seekRuler`, `_tracks`)
4. 없음

## 현재 상태
- `_tracks`의 `Listener.onPointerDown`이 룰러 높이 안에서 `_seekRuler`만 호출한다.
- 가로 스크롤은 `SingleChildScrollView`지만, 룰러를 잡고 패닝하는 제스처는 없다.

## 바꿀 것
1. `_ruler`에 가로 드래그 → `_scrollController` 이동(패닝).
2. 룰러 탭 → 기존 시크 유지.
3. 드래그 중 커서 `grab`/`grabbing`.
4. 전체 `Listener`의 룰러 시크는 룰러 제스처로 옮기고 충돌 없게 정리한다.

## 유지할 것
- 트랙 클릭 시크·클립 드래그 편집·pps·가용 가로 채움

## 이번 작업에서 만들지 않음
- 휠 줌
- 트랙 영역 전체 패닝
- 새 스크롤바 위젯

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
