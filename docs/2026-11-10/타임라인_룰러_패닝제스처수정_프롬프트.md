# 타임라인 룰러 패닝이 ScrollView와 충돌하지 않게 고친다

## 목표
룰러를 마우스로 드래그하면 가로 스크롤이 실제로 움직이고, 짧게 누를 때만 시크된다.

## 현재 상태
- 로컬 로그에 `[RULER] ... scroll=0.0` 시크만 반복된다. `GestureDetector` 가로 드래그가 `SingleChildScrollView`와 경쟁하며 패닝이 먹지 않는다.

## 바꿀 것
1. 룰러 패닝·시크를 `Listener` 포인터 이벤트로 처리한다(드래그 델타로 `jumpTo`, 이동 없으면 탭 시크).
2. grab/grabbing 커서는 유지한다.

## 유지할 것
- 가용 가로 채움·트랙 시크·클립 편집

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
