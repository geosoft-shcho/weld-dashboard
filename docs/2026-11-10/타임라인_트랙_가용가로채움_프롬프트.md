# 타임라인 트랙이 가용 가로를 채우게 한다

## 목표
사이드가 닫혀 있으면 타임라인 트랙이 가용 가로를 채우고, 사이드가 열리면 그만큼 트랙 영역이 줄어든다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md` (가이드라인 저장소는 워킹 트리 밖에서 읽기만)
3. `lib/src/presentation/features/video_multimodal/widgets/multimodal_timeline_board.dart` (`_tracks`)
4. `lib/src/presentation/features/video_multimodal/video_multimodal_screen.dart` (`_WorkspaceHost`, `_SidePanelHost`)
5. 없음

## 현재 상태
- 사이드가 `none`이면 `_SidePanelHost`는 `SizedBox.shrink()`이고 stage/timeline은 `Expanded`다.
- `_tracks` 캔버스 폭은 `viewModel.trackWidth`(span × pps)만 써서, 뷰포트보다 짧으면 오른쪽에 빈 칸이 남는다.

## 바꿀 것
1. `_tracks`에서 트랙/룰러 폭을 `max(viewModel.trackWidth, constraints.maxWidth)`로 잡는다.
2. 사이드 열림·닫힘은 기존 `Row` + `_SidePanelHost` 배치를 유지한다.

## 유지할 것
- 가로 스크롤·pps·사이드 패널 폭(320/360)
- 진입 시 `side = none`
- playhead·마커·클립 배치 계산

## 이번 작업에서 만들지 않음
- 자동 줌(pps) 변경
- NavigationPane 숨김
- 사이드를 Stack 오버레이로 전환

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
