# 패스 표 Row 열 비율을 2:1:1:1로 맞춘다

## 목표
패스 표 Row 열이 2:1:1:1(패스:시작:종료:액션) 비율이다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md` (가이드라인 저장소는 워킹 트리 밖에서 읽기만)
3. `lib/src/presentation/features/job_lookup/widgets/job_pass_tab.dart`
4. 없음

## 현재 상태
- 헤더·데이터 행이 패스 고정폭·시작/종료 Expanded·액션 고정폭과 열 간격 상수를 쓴다.

## 바꿀 것
1. 헤더·데이터 행 모두 `Expanded(flex: 2/1/1/1)`로 통일한다.
2. `_passColWidth`·`_passColGap`·`_passActionColWidth`를 제거한다.

## 유지할 것
- 수정·지우기 버튼·다이얼로그·삭제·빈 상태

## 이번 작업에서 만들지 않음
- 공통 테이블 위젯 추출
- 다른 화면 표 수정

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
