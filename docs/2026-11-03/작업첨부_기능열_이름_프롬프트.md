# 첨부 테이블 기능 열 이름

## 목표
에셋 상세·떼기 버튼이 있는 열을 **기능**이라는 헤더 이름으로 보이게 한다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md`
3. `lib/src/presentation/features/job_lookup/widgets/job_attachment_tab.dart` `_JobAttachmentTableHeader`와 행 끝 IconButton들

## 현재 상태
- 행 끝에 에셋 상세·떼기 `IconButton`이 있다.
- 헤더는 그 자리를 빈 `SizedBox(width: 60)`만 두고 이름이 없다.

## 바꿀 것
1. `_JobAttachmentTableHeader`에서 빈 `SizedBox(width: 60)`을 `Text('기능', style: headerStyle)`로 바꾼다(너비 60 유지, 행 버튼 열과 맞춤).
2. 행의 버튼·Tooltip·동작은 그대로 둔다.

## 유지할 것
- 번호·종류·파일·후처리·패스 열, 상세 이동·떼기 동작

## 이번 작업에서 만들지 않음
- 버튼 문구를 아이콘 대신 텍스트로 바꾸기
- 행 전체 탭/더블클릭

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.

## 완료 확인
- 첨부 표 헤더에 **기능**이 보이고 아래에 상세·떼기 버튼이 정렬된다
