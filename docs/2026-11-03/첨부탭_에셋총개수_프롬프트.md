# 첨부 탭 에셋 총개수 UI

## 목표
작업 상세 탭바는 `첨부`만 두고, 에셋 총개수는 첨부 탭 안에서 ListAssets 조회 후 보여 준다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md`
3. `lib/src/presentation/features/job_lookup/widgets/job_detail_tabs_bar.dart`
4. `lib/src/presentation/features/job_lookup/widgets/job_attachment_tab.dart`
5. `lib/src/presentation/features/job_lookup/job_lookup_detail_screen.dart`
6. `lib/src/presentation/features/job_lookup/job_lookup_detail_view_model.dart` `_attachmentsTotalCount` / `attachmentCount` 동기화
7. 계약·화면안: 없음

## 현재 상태
- 탭바: `'첨부 $attachmentCount'` + `attachmentCount` 인자.
- 화면: `JobDetailTabsBar(attachmentCount: job.attachmentCount, ...)`.
- ViewModel에 `_attachmentsTotalCount`는 있으나 public getter 없음. 첨부 로드 후 `detail`/`job.attachmentCount`에 동기화됨.
- 첨부 탭에는 총개수 UI 없음.

## 바꿀 것
1. **탭바** — `attachmentCount` 파라미터 제거. 라벨을 `'첨부'`만 사용.
2. **화면** — `JobDetailTabsBar` 호출에서 `attachmentCount` 인자 제거.
3. **ViewModel** — `int get attachmentTotalCount` 추가: `_attachmentsTotalCount > 0`이면 그 값, 아니면 `detail?.attachmentCount ?? job?.attachmentCount ?? 0`.
4. **첨부 탭 UI** — 액션바 아래(목록 위)에 `에셋 총 N건` 텍스트. 로드 완료 후에만 표시. ViewModel에 `bool get didLoadAttachments => _didLoadAttachments` getter 추가.

표시 위치: `JobDetailActionBar`와 목록/empty 사이, `Text('에셋 총 ${viewModel.attachmentTotalCount}건', style: fontSize 13, color AppTheme.STATUS_OFF)` 한 줄. 카드/새 위젯 파일 없이 인라인.

## 유지할 것
- 패스 탭 `패스 $passCount`
- 첨부 목록·인피니트 스크롤·올리기/붙이기
- ListAssets 지연 로드 흐름

## 이번 작업에서 만들지 않음
- 탭바 디자인 전면 변경
- ViewModel attachmentCount 동기화 로직 재설계
- 작업상세(work_detail) 화면

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
