# 코멘트 목록 사이드 패널

## 목표
녹화 창은 영상 녹화와 글 입력만 한다. 코멘트 목록·수정·삭제는 멀티모달 툴바의 코멘트 버튼이 여는 사이드 패널에서 한다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md`
3. `lib/src/presentation/features/video_multimodal/widgets/camera_recording_dialog.dart`
4. `lib/src/presentation/features/video_multimodal/widgets/multimodal_page_toolbar.dart`
5. `lib/src/presentation/features/video_multimodal/widgets/multimodal_side_panel.dart`
6. `lib/src/presentation/features/video_multimodal/widgets/screen_comment_list.dart`

## 현재 상태
- 녹화 카드가 글 입력과 `ScreenCommentList`를 함께 보여 준다.
- 품질·패스도 같은 녹화 카드의 목록을 쓴다.
- 멀티모달 사이드 패널은 Assets, Properties, Labels, 질문이다. 코멘트 패널은 없다.

## 바꿀 것
1. 녹화 창에서 목록과 목록 다시 불러오기 전달을 뺀다. 글 입력은 남긴다.
2. Assets·Properties·Labels 묶음에 코멘트 버튼을 넣고, 같은 사이드 전환으로 코멘트 패널을 연다.
3. 패널 본문은 기존 목록의 내용·상태·저장·삭제를 쓰고, 패널 높이에 맞춰 스크롤한다.
4. 업로드 뒤 `commentListReloadCount`가 늘면 열린 패널 목록을 다시 불러온다.

## 유지할 것
- CreateComment, 품질·패스의 글 입력과 업로드, 멀티모달 클립 배치
- 목록 API는 `ListComments{jobId}`

## 이번 작업에서 만들지 않음
- 품질·패스 목록 패널
- 재생 되살리기, 공통 헤더 이동, proto 재생성

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
