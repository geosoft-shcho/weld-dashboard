# 비영상 클립 대상 영상 스테이지

## 목표
타임라인에서 영상 클립이 아닌 클립을 골랐을 때, GetClip 「대상 파일」(targetAsset)이 영상이면 스테이지에서 그 영상을 재생한다. 대상 영상이 없고 덮는 트랙 영상도 없으면 스테이지 전체를 가리는 문구 대신 안내 배너만 보이게 한다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md`
3. `lib/src/presentation/features/video_multimodal/widgets/multimodal_video_stage.dart`
4. `lib/src/presentation/features/video_multimodal/video_multimodal_view_model.dart` (`_loadClipDetail`, `_startPosePlayback`, `_activeVideoClip`, `_playbackVideoClip`)
5. `lib/src/domain/entities/job_timeline.dart` (`ClipDetail`), `lib/src/data/repositories/clip_detail_mapping.dart`
6. 계약·화면안: 없음

## 현재 상태
- 스테이지는 `activeVideoBar` ← `_activeVideoClip()`이다. 같은 트랙의 영상 클립이 playhead를 덮을 때만 재생한다.
- 포즈만 `targetClip=VIDEO` + `targetAsset` URL로 `_playbackVideoClip`을 두고 재생한다.
- 그 외 비영상은 `_startVideoRange`가 `!isVideo`면 바로 return한다.
- `activeVideoBar == null`이면 스테이지 전체에 「고른 트랙에서 이 시각을 덮는 영상이 없습니다」를 가운데 띄운다.

## 바꿀 것
1. `ClipDetail`에 대상 파일이 영상인지 표시(`isTargetAssetVideo`). 매핑에서 `ASSET_KIND_VIDEO`로 채운다.
2. 비영상·비포즈 클립 상세 로드 후, 포즈와 같은 조건이면 대상 영상으로 `_playbackVideoClip`을 세우고 seek한다.
   - `hasTargetClip` && `targetClipKind == 'VIDEO'`
   - `hasTargetAsset` && `isTargetAssetVideo` && `targetAssetContentUrl` 비어 있지 않음
   - 대상 클립 타임라인 구간으로 `TimelineClip` 구성(포즈의 video 구성과 동일 패턴)
3. `_activeVideoClip`: 선택 클립이 영상이 아니고 `_playbackVideoClip`이 playhead를 덮으면 그것을 쓴다. 포즈는 기존처럼 덮지 않으면 null(트랙 영상으로 떨어지지 않음). 그 외 비영상은 playback이 없으면 기존 `_videoOnSelectedTrack`으로 떨어진다.
4. `multimodal_video_stage.dart` `_singleLegacy`: 영상 없을 때 전체 Center 문구 대신 `ColoredBox` + 하단(또는 모서리) 안내 배너만 표시. 문구·playheadLabel은 유지.
5. 포즈 재생·모니터 그리드 슬롯 빈 문구·ViewModel 시그니처 대청소는 하지 않는다.

## 유지할 것
- 포즈 오버레이·좌표 로드 경로
- 영상 클립 선택 시 `_startVideoRange`
- 모니터 그리드 `_slot`의 「이 시각에 영상 없음」문구(이번 범위 밖)
- timeline_board 선택 → `_loadClipDetail` 흐름

## 이번 작업에서 만들지 않음
- targetClip 없이 targetAsset만 있을 때의 임의 구간 재생
- 모니터 슬롯 UI 변경
- 서버 API·proto 변경

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.

## 완료 확인
- 비영상 클립 + 대상 영상 클립/파일이 있으면 스테이지에 그 영상이 나온다.
- 대상 영상이 없으면 직전 스테이지 영상은 그대로 두고 하단 안내 배너만 올린다. 직전 영상도 없으면 빈 스테이지 + 배너.
- 포즈 선택·오버레이는 이전과 같다.
