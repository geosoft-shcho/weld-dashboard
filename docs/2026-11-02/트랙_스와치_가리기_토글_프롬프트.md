# 트랙 스와치 가리기 토글

## 목표
타임라인 트랙 헤더의 장식용 색 박스를 탭하면 해당 레인/트랙을 숨기고, 다시 켜기는 기존 `_laneMenu`로만 한다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md`
3. `lib/src/presentation/features/video_multimodal/widgets/multimodal_timeline_board.dart` (`_trackLabel` 스와치, `_laneMenu`)
4. `lib/src/presentation/features/video_multimodal/video_multimodal_view_model.dart` (`didTapToggleLaneKey`, `isLaneVisible`)
5. 계약·화면안: 없음

## 현재 상태
- `_trackLabel` 12×12 `Container`는 kind 색만 표시하고 탭이 없다.
- 같은 헤더의 모니터·차트 아이콘은 `GestureDetector`로 ViewModel을 호출한다.
- `didTapToggleLaneKey` / `_hiddenLaneKeys` / `isLaneVisible`이 이미 있고, `buildTimelineBoardRows`는 숨긴 트랙 행을 그리지 않는다.
- `_laneMenu` 체크박스가 숨긴 트랙을 다시 켠다.

## 바꿀 것
1. `_trackLabel` 스와치를 `GestureDetector`로 감싼다.
   - `onTap: () => viewModel.didTapToggleLaneKey(row.laneKey)`
   - 부모 행의 클립 선택 `GestureDetector`와 충돌하지 않게, 모니터 아이콘과 같은 중첩 탭 패턴을 쓴다.
2. `Tooltip(message: '트랙 가리기')`로 의미를 밝힌다.
3. 스와치 크기·색(`swatch`/`border`)·마진은 유지한다.
4. `_laneMenu`·`didTapToggleLaneKey`·행 필터 로직은 수정하지 않는다.

## 유지할 것
- 레인 메뉴로 다시 보이기
- 숨김 시 보드에서 행 제거 동작
- 모니터·차트 토글

## 이번 작업에서 만들지 않음
- 숨긴 트랙용 접힌 헤더 행
- 서버 동기화
- ViewModel 시그니처 변경·`timelineHint` 추가(이번엔 Tooltip만)

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.

## 완료 확인
- 스와치 탭 시 해당 트랙 행이 보드에서 사라진다.
- `_laneMenu`에서 다시 체크하면 행이 돌아온다.
- 스와치 탭이 클립 선택으로만 처리되지 않는다.
