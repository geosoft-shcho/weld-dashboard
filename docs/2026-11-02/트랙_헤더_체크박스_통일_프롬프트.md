# 트랙 헤더 체크박스 통일

## 목표
트랙 헤더의 가리기 컨트롤을 `_laneMenu`와 같은 체크박스로 통일한다. 헤더가 보이는 트랙은 체크된 체크박스로 보이고, 탭하면 가린다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md`
3. `lib/src/presentation/features/video_multimodal/widgets/multimodal_timeline_board.dart` (`_trackLabel` 784–799, `_laneMenu` 체크 아이콘)
4. 계약·화면안: 없음

## 현재 상태
- 헤더는 색 `Container` 스와치 + `didTapToggleLaneKey` + Tooltip `'트랙 가리기'`.
- `_laneMenu`는 `Icons.check_box` / `Icons.check_box_outline_blank` (size 16, SAND_700).
- 보드에 그려진 행은 이미 보이는 트랙뿐이므로 헤더 체크는 항상 checked가 맞다.

## 바꿀 것
1. `_trackLabel`의 스와치 `Container`를 제거하고, 레인 메뉴와 동일하게:
   - `Icons.check_box` (헤더에 보이면 항상 체크)
   - `GestureDetector` → `didTapToggleLaneKey(row.laneKey)`
   - `Tooltip(message: '트랙 가리기')` 유지
   - 아이콘 size/color는 메뉴와 맞춤 (16, SAND_700), 오른쪽 여백은 기존과 비슷하게 유지
2. `_trackLabel`의 `swatch`/`border` 인자와 호출부의 색 전달이 더 이상 쓰이지 않으면 제거한다.
3. `_laneMenu`·ViewModel 토글 로직은 수정하지 않는다.

## 유지할 것
- `didTapToggleLaneKey` / 숨김 후 행 제거 / 메뉴로 다시 켜기
- 모니터·차트 아이콘

## 이번 작업에서 만들지 않음
- 헤더에 unchecked 상태 표시(숨긴 행은 보드에 없음)
- 서버 동기화

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.

## 완료 확인
- 보이는 트랙 헤더에 체크된 체크박스가 있다.
- 탭하면 트랙이 숨겨지고, 레인 메뉴에서 다시 켤 수 있다.
- 색 스와치 박스는 헤더에 없다.
