# 트랙 라벨 아이콘 순서·일관 표시

## 목표
`_trackLabel`에서 가리기(`check_box`)를 맨 앞에 두고, volume 아이콘이 같은 크기·간격·위치로 일관되게 보이게 한다.

## 권장 안
1. **순서:** `가리기 → volume → 모니터 → 차트 → AI → 이름`  
   가리기는 모든 트랙 공통이므로 맨 앞 고정. volume은 소리 가능한 트랙만, 가리기 바로 다음 슬롯.
2. **시각:** 토글 아이콘 크기 14, `padding right: 4`로 통일(기존 check_box 16/6 해소). volume에도 Tooltip.
3. **표시 조건:** volume은 기존 `trackShowsAudioMuteToggle` 유지(영상·음성 클립 있을 때만). 자리만 가리기 뒤로 고정.

## 바꿀 것
1. `multimodal_timeline_board.dart` `_trackLabel` Row 자식 순서·패딩·크기·volume Tooltip.

## 유지할 것
- mute/모니터/차트 토글 동작
- volume 표시 조건(`trackShowsAudioMuteToggle`)

## 이번 작업에서 만들지 않음
- 소리 없는 트랙에 비활성 volume 상시 노출
- 라벨 폭 알고리즘 개편

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
