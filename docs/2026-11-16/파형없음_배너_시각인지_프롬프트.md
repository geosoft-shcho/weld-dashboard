# 파형 없음 안내 시각 인지 개선

## 목표
차트·비교 지표를 같이 볼 때 파형 없음 안내가 부제처럼 묻히지 않고, **짧은 상태 스트립**으로 한눈에 구분되게 한다.

## 레이아웃 진단 (현재)
- 배너가 `_PassChartPane`(flex 8) 안에만 있어 **비교 지표(flex 2)와 정렬·폭이 어긋남**.
- `STATUS_OFF` 본문 텍스트만이라 차트 헤더·축 라벨과 비슷해 **상태 안내로 인지되기 어려움**.
- InfoBar보다 공간은 줄었지만, 비교 지표까지 포함한 한 화면 구성에서는 존재감이 약함.

## 바꿀 것
1. `pass_profile_screen.dart`만 수정.
2. `_PassChartPane`에서 banners 표시 제거.
3. `_PassProfileReady`에서 툴바 아래 · `차트|비교지표` Row **위**에 전체 폭 안내를 둔다.
4. 표시 형태 (세로는 얇게 유지):
   - `SURFACE_RAISED` + radius 4 + 왼쪽 `STATUS_WARN` 3px border
   - 패딩 수평 10 · 수직 6
   - 본문: `banners.join(' · ')`, fontSize 12, fontWeight w600 (본문보다 안내로 읽히게)
   - 색은 기본 전경(또는 STATUS_WARN보다 약한 톤이 필요하면 전경 + 액센트만 WARN)
5. board banners가 비어 있으면 블록 자체를 그리지 않음.
6. 시리즈 에러 InfoBar·로딩 ProgressBar는 `_PassChartPane`에 유지.

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
