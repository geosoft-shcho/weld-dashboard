# multimodal_timeline_board 파일 분리 리팩터

## 목표
`multimodal_timeline_board.dart`를 책임별 위젯 파일로 나눠 관리한다. 동작은 바꾸지 않는다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md` + guidelines 폴더 구조(위젯은 `presentation/.../widgets/`)
3. `lib/src/presentation/features/video_multimodal/widgets/multimodal_timeline_board.dart`
4. 기존 `timeline_board_helpers.dart` (row/clip 모델·레이아웃 계산 — 유지)

## 현재 상태
한 StatefulWidget에 셸·스크롤, 툴바·편집 도구·트랙 메뉴, 트랙 라벨, 룰러·플레이헤드, 트랙·클립·리사이즈가 섞여 있다. helpers에 row/clip 모델은 이미 있다.

## 바꿀 것
1. `timeline_board_toolbar.dart` — TimelineBoardToolbar, TimelineBoardTrackMenu
2. `timeline_board_track_labels.dart` — TimelineBoardTrackLabels
3. `timeline_board_clip_bar.dart` — TimelineBoardClipBar
4. 보드는 props/콜백으로 연결. 룰러·편집 State·스크롤 동기는 보드에 남김.

## 유지할 것
- mute/모니터/차트/가리기·Tooltip·원형 버튼 동작
- helpers API
- 화면은 MultimodalTimelineBoard만 import

## 이번 작업에서 만들지 않음
- part/part of 기계적 쪼개기
- 새 Coordinator·UseCase·상태관리
- 룰러·편집 엔진 분리
- UI/동작 변경

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
