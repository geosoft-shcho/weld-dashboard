# 비교 지표 채널 표시 순서

## 목표
비교 지표 UI 행이 차트와 같이 **전류 → 전압 → 속도 → 회전 속도** 순으로 보이게 한다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md`
3. `lib/src/presentation/core/widgets/waveform_channel_charts.dart`
4. `lib/src/data/repositories/remote_pass_waveform_repository.dart` (`_compareSummaryFromResponse`, `_compareChannelLabel`)
5. `lib/src/presentation/features/pass_profile/widgets/pass_compare_summary.dart`

## 현재 상태
- 차트: 전류 → 전압 → 속도 → 회전 속도 고정.
- `_compareSummaryFromResponse`는 서버 `compare_summary` 순서를 그대로 유지(라벨만 한글화).

## 바꿀 것
1. `remote_pass_waveform_repository.dart`에서 라벨 매핑 후 목록을 차트 순으로 정렬:
   - `전류` = 0, `전압` = 1, `속도` = 2, `회전 속도` = 3
   - 그 외 채널은 네 용접 채널 뒤에 두고, 서로 간에는 서버 순서 유지
2. UI·엔티티 시그니처는 변경하지 않음.

## 유지할 것
- 한글 라벨·mean_diff/similarity/`-` 표시
- `PassCompareSummary` 표 구조
- quality_issue 화면

## 이번 작업에서 만들지 않음
- 차트 위젯 변경
- 공통 정렬/라벨 추상 계층

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
