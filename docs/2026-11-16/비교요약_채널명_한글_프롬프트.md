# 비교 요약 채널명 한글 표시

## 목표
`PassCompareSummary` 채널 열이 `current_a` 대신 차트와 같은 한글(`전류`, `전압`, `속도`, `회전 속도`)로 보이게 한다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md`
3. `lib/src/data/repositories/remote_pass_waveform_repository.dart` (`_rowsFromWaveform`, `_compareSummaryFromResponse`, `_channelKey`)
4. `lib/src/presentation/core/widgets/waveform_channel_charts.dart` (차트 제목)
5. `lib/src/presentation/features/pass_profile/widgets/pass_compare_summary.dart`

## 현재 상태
- `_compareSummaryFromResponse`가 `channelName: item.name`으로 서버 키(`current_a` 등)를 그대로 넣음.
- `_rowsFromWaveform`은 `_channelKey(channel.name)`로 같은 채널을 `currentA`/`voltageV`/`speedValue`/`rotationSpeedRpm` 필드에 매핑.
- 차트 표시명: `전류`, `전압`, `속도`, `회전 속도` (단위는 제목/축에만).

## 바꿀 것
1. `remote_pass_waveform_repository.dart`의 `_compareSummaryFromResponse`에서 `channelName`을 `_channelKey` + `_rowsFromWaveform`과 동일 case로 한글 라벨에 매핑:
   - `current_a` / `current_A` / `전류_a` → `전류`
   - `voltage_v` / `전압_v` → `전압`
   - `wire_feed_speed_mpm` / `wire_speed_mpm` / `와이어송급속도_m_min` → `속도`
   - `rotation_speed_rpm` / `rpm` → `회전 속도`
   - 그 외 → 원본 `item.name` 유지
2. 단위 열·mean_diff·similarity 매핑은 그대로. UI 위젯·엔티티 시그니처 변경 없음.

## 유지할 것
- `PassCompareSummary` 표 구조·포맷(`+12.3 A`, `0.82`, `-`)
- `_rowsFromWaveform`의 파형 row 조립
- quality_issue 화면

- 차트 제목 문구 변경
- IMU 등 비용접 채널 전용 UI

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
