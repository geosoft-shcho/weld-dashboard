# 데스크탑 컨트롤 Spacer 좌우 정렬

## 목표
하단 컨트롤 Row를 왼쪽(재생·mute·시간) / 오른쪽(fullscreen)으로 나누고, 좁은 폭에서도 overflow 없이 유지한다.

## 현재 상태
- `Flexible(시간)`과 `Spacer`가 둘 다 flex라 남는 폭을 나눠 먹어 좌우 정렬이 깨진다.

## 바꿀 것
1. 왼쪽: `Expanded` + 안쪽 `Row`(play, mute, `Flexible` 시간 ellipsis).
2. 오른쪽: fullscreen 아이콘(있으면).
3. 바깥 `Spacer`·시간만의 단독 `Flexible`+`Spacer` 조합 제거.

## 유지할 것
- 재생·mute·fullscreen 동작, 오버플로 방지(ellipsis)

## 이번 작업에서 만들지 않음
- stage 최소 폭, 새 컨트롤 바

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
