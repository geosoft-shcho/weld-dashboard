# 목록 동작 버튼 아이콘+라벨

## 목표
계정 관리·역할 관리 목록의 동작 열에서 텍스트만 버튼 대신 **아이콘 + 버튼명**을 쓰고, 라벨을 수정/삭제로 맞춘다.

## 먼저 읽을 것
- [accounts_admin_screen.dart](lib/src/presentation/features/account_admin/accounts_admin_screen.dart) `actionsBuilder` (약 77–83행)
- [roles_admin_screen.dart](lib/src/presentation/features/account_admin/roles_admin_screen.dart) `actionsBuilder` (약 76–91행)

## 현재 상태
- 계정: `Button` + `Text('고치기')`  alone
- 역할: `Button` + `Text('고치기')` / `Text('지우기')`
- 다이얼로그 제목(`계정 고치기` 등)은 이번 범위 밖

## 바꿀 것
1. **계정 목록** — 동작 버튼을 `Icon(FluentIcons.edit, size: 12)` + `Text('수정')` Row child로 변경
2. **역할 목록** — 고치기→같은 패턴 `수정`, 지우기→`Icon(FluentIcons.delete, size: 12)` + `Text('삭제')`
3. 아이콘·텍스트 간격은 `SizedBox(width: 6)` 정도, 기존 `Button`/`onPressed` 유지

## 복잡한 코드 제거 및 금지
- 새 공용 위젯·헬퍼·추상 계층을 만들지 않는다.
- 서비스 토큰 목록·다이얼로그 제목·확인 다이얼로그 문구는 건드리지 않는다.
- 범위 밖 리팩터·스타일 통일을 하지 않는다.

## 완료 확인
- `./scripts/agent_check.sh` 통과
- 계정 목록 동작: 연필 아이콘 + 「수정」
- 역할 목록 동작: 연필+「수정」, 휴지통+「삭제」
- 다이얼로그 제목은 기존 문구 유지
