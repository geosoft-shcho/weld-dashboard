# P4 작성자 표시 확장

## 목표
Pass · Clip · Comment · Timeline · Track · LabelValue · ReviewItem 목록/상세에 `created_by` · `updated_by` 표시명을 넣고, 비면 `authorDisplayLabel` → 「시스템」으로 보인다. P3 권한 숨김은 하지 않는다.

## 먼저 읽을 것
- [author_display.dart](lib/src/presentation/core/widgets/author_display.dart)
- 1차 패턴: [job_info_tab.dart](lib/src/presentation/features/job_lookup/widgets/job_info_tab.dart), [asset_lookup_detail_screen.dart](lib/src/presentation/features/asset_lookup/asset_lookup_detail_screen.dart)
- [로그인_권한_남은작업.md](docs/2026-11-23/로그인_권한_남은작업.md) 「작성자 표시 확장」
- Proto: Pass(`work`), Comment(`asset`), Timeline/Track/Clip/LabelValue(`compose`), ReviewItem(`report`) — generated에 Author 필드 이미 있음

## 현재 상태
- Proto·생성 코드에 Author 있음. 앱 domain/매핑/UI는 공사·작업자·장비·작업·파일만 연결됨.
- P4 7개 엔티티는 domain에 author 필드 없고 UI 미표시.
- `tool.manage`/병합 UI·P3는 이번 작업 아님.

## 바꿀 것

### 공통
- 빈 표시는 기존 `authorDisplayLabel`만 쓴다. 새 포맷터·추상 계층을 만들지 않는다.
- 매핑: `proto.hasCreatedBy() ? proto.createdBy.displayName : ''` (updated 동일)

### Domain 필드 추가 (`createdByDisplayName` / `updatedByDisplayName`)
- Pass: [job_detail.dart](lib/src/domain/entities/job_detail.dart) `JobPassDetail` (+ 생성·copy 호출부)
- Clip: clip/timeline 관련 domain (`ClipDetail` / `TimelineClip` 등 실제 타입)
- Comment: `ScreenComment`
- Timeline: `JobTimeline`
- Track: `TimelineTrack`
- LabelValue: `LabelNode`
- ReviewItem: `ReportReviewRow`

### Data 매핑
- [remote_job_admin_repository.dart](lib/src/data/repositories/remote_job_admin_repository.dart) — Pass
- clip detail mapping — Clip
- [remote_job_timeline_repository.dart](lib/src/data/repositories/remote_job_timeline_repository.dart) — Timeline · Track
- Comment 매핑 repo (`remote_asset_upload_repository` 등)
- label 매핑 — LabelValue
- [remote_report_set_repository.dart](lib/src/data/repositories/remote_report_set_repository.dart) — ReviewItem

## 복잡한 코드 제거 및 금지
- 새 공용 Author 위젯 팩토리·전략·제네릭 헬퍼를 만들지 않는다. 기존 KV/한 줄 텍스트 패턴만 복제한다.
- P3 권한 게이팅·`hasPermission` 도입·메뉴 숨김을 하지 않는다.
- generated proto 수정 금지. `corrected_by` 레거시 정리·도구 관리 UI는 하지 않는다.
- 범위 밖 리팩터·이름 통일 금지.
