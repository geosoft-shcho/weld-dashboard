# (2026-11-25) 작성자 표시 P4 화면 검증

| 항목 | 값 |
|------|-----|
| 근거 | [`작성자표시_P4_프롬프트.md`](./작성자표시_P4_프롬프트.md), [`로그인_권한_남은작업.md`](../2026-11-23/로그인_권한_남은작업.md) 「작성자 표시 확장」 |
| 표시 규칙 | `created_by` · `updated_by` 표시명. 비면 `authorDisplayLabel` → **시스템** |
| 대상 | Pass · Clip · Comment · Timeline · Track · LabelValue · ReviewItem |
| 권한 | 이번 검증에서 버튼 숨김(P3)은 보지 않는다 |

이 문서는 **지금 앱에서 손으로 검증하는 절차**다. 코드를 고치지 않는다.

---

## 1. 화면에서 무엇이 보이는지

| 대상 | 진입 | 표시 위치 |
|------|------|-----------|
| Pass | 작업 조회 상세 → 패스 탭 → 패스 **고치기** 다이얼로그 하단 | `작성자: … · 수정자: …` |
| Clip | 멀티모달 → 클립 선택 → Properties KV | **작성자** · **수정자** 행 |
| Comment | 멀티모달 → 화면 코멘트 목록 타일 메타 | `작성자: … · 수정자: …` |
| Timeline | 멀티모달 → 타임라인 이름/설명 저장 다이얼로그 | `작성자: … · 수정자: …` |
| Track | 멀티모달 보드 → 트랙 라벨 **tooltip** | `작성자: … · 수정자: …` |
| LabelValue | 멀티모달 → Labels 사이드 → 노드 선택 보조 문구 | `작성자: … · 수정자: …` |
| ReviewItem | 작업 상세 → 성적서/확인 패널 확인 목록 | `작성자 / 수정자` 열(또는 행 보조) |

공통: 서버 Author가 없으면 칸에 **시스템**. 표시명이 있으면 그 문자열 그대로.

---

## 2. 검증 준비

1. 로그인 가능한 계정으로 앱을 띄운다(조회만 되어도 됨. P3 권한 숨김은 이번 범위 밖).
2. 아래가 **채워진** 작업·자산을 하나 고른다.
   - 패스가 있는 작업
   - 타임라인·트랙·클립·라벨·화면 코멘트가 있는 멀티모달 대상
   - 확인(Review) 행이 있는 성적서/작업 상세
3. (권장) Author가 **있는** 행과, 후처리·도구·옛 데이터로 Author가 **비는** 행을 각각 하나 이상 확보한다.
4. Chrome DevTools → Network에서 `ListPasses` · `GetClip`/`ListClips` · Comment list · Timeline/Track · Label · ReportSet 응답에 `createdBy`/`updatedBy`(또는 동등 필드)가 오는지 필요 시 확인한다.

---

## 3. 시나리오별 검증

### A. Pass

| 단계 | 조작 | 기대 |
|------|------|------|
| A1 | 작업 조회 → 패스가 있는 작업 상세 → **패스** 탭 | 패스 목록 정상 |
| A2 | 패스 **고치기**(또는 수정 다이얼로그) 열기 | 하단(또는 메타)에 `작성자: … · 수정자: …` |
| A3 | API에 Author 있는 패스 | 표시이름이 보임(빈 문자열·null UI 없음) |
| A4 | Author 없는 패스(또는 필드 없음) | **시스템** |

### B. Clip

| 단계 | 조작 | 기대 |
|------|------|------|
| B1 | 멀티모달에서 클립 하나 선택 | Properties(또는 클립 상세 KV) 열림 |
| B2 | KV에서 **작성자** · **수정자** 행 확인 | 라벨이 「작성자」「수정자」로 보임 |
| B3 | Author 있는 클립 / 없는 클립 | 표시명 또는 **시스템** |

### C. Comment

| 단계 | 조작 | 기대 |
|------|------|------|
| C1 | 멀티모달 → 화면 코멘트 목록 | 타일마다 메타 줄에 `작성자: … · 수정자: …` |
| C2 | 사람이 만든 코멘트 | 작성자(·수정자)에 표시이름 |
| C3 | Author 비는 코멘트 | **시스템** |
| C4 | (선택) 코멘트 고친 뒤 목록 새로고침 | 수정자가 갱신되었으면 반영(서버가 내려줄 때) |

### D. Timeline

| 단계 | 조작 | 기대 |
|------|------|------|
| D1 | 멀티모달에서 타임라인 **이름/설명** 저장(또는 편집) 다이얼로그 열기 | 하단에 `작성자: … · 수정자: …` |
| D2 | Author 유무 | 표시명 또는 **시스템** |

### E. Track

| 단계 | 조작 | 기대 |
|------|------|------|
| E1 | 타임라인 보드에서 트랙 **라벨**에 마우스 올림(tooltip) | `작성자: … · 수정자: …` 포함 |
| E2 | Author 유무 | 표시명 또는 **시스템** |

### F. LabelValue

| 단계 | 조작 | 기대 |
|------|------|------|
| F1 | Labels 사이드에서 라벨 노드 **선택** | 선택 보조 문구에 `작성자: … · 수정자: …` |
| F2 | Author 유무 | 표시명 또는 **시스템** |

### G. ReviewItem

| 단계 | 조작 | 기대 |
|------|------|------|
| G1 | 작업 상세 → 성적서/확인 패널 → 확인 목록 | 행에 작성자/수정자(`이름 / 이름` 형태) |
| G2 | Author 있는 확인 행 / 없는 행 | 표시명 또는 **시스템** |

### H. 회귀 (1차 작성자 표시)

| 단계 | 조작 | 기대 |
|------|------|------|
| H1 | 공사 상세 | 작성자 · 수정자 칸 유지, 빈 값 **시스템** |
| H2 | 작업자 · 장비 상세 | 동일 |
| H3 | 작업 정보 탭 | `작성자: … · 수정자: …` 유지 |
| H4 | 파일(Asset) 상세 | 작성자 · 수정자 KV 유지 |

### I. 스모크 · 깨짐 방지

| 단계 | 조작 | 기대 |
|------|------|------|
| I1 | 위 화면을 Author 없는 데이터만으로 연다 | 빈칸·예외 없이 전부 **시스템** |
| I2 | 패스/코멘트/라벨 등 목록 스크롤·다이얼로그 열고 닫기 | 레이아웃 깨짐·오버플로 없음(긴 표시이름 있으면 잘림·줄바꿈만 허용) |
| I3 | P4 화면에서 편집 버튼이 **보이던** 계정으로 확인 | 이번 작업으로 버튼이 갑자기 숨겨지지 않음(P3 미적용) |
