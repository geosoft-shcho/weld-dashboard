# 역할 관리 → 권한 관리 문구

## 목표
셸·네비·권한(구 역할) 관리 화면에 보이는 「역할 관리」「역할」 문구를 「권한 관리」「권한」으로 맞춘다. 권한 개수 열은 「권한 수」로 구분해 혼동을 막는다.

## 먼저 읽을 것
- [shell_screen.dart](lib/src/presentation/features/app_shell/shell_screen.dart) 메뉴 `label: '역할 관리'`
- [app_coordinator.dart](lib/src/presentation/navigation/app_coordinator.dart) pane 타이틀 `'역할 관리'`
- [roles_admin_screen.dart](lib/src/presentation/features/account_admin/roles_admin_screen.dart) 헤더·빈 목록·다이얼로그·삭제 확인
- [roles_admin_view_model.dart](lib/src/presentation/features/account_admin/roles_admin_view_model.dart) 검증 메시지

## 현재 상태
- 메뉴/타이틀: 「역할 관리」
- 화면: 「역할」, 「+ 새 역할」, 「역할이 없습니다」, 「역할 지우기」, 「새 역할」/「역할 고치기」, hint 「역할 이름」
- 목록 열: `['이름', '설명', '권한']` (세 번째는 permission 개수)
- 계정 관리의 「역할」 열·콤보·「역할을 고르세요」는 계정에 역할(권한 묶음)을 고르는 필드로 유지

| 삭제 확인 제목·본문 | 역할 지우기 / …역할을 지울까요? → **권한 삭제** / **…권한을 삭제할까요?** |
| 편집 다이얼로그 제목 | 새 역할 / 역할 고치기 → **새 권한** / **권한 수정** |
| 이름 hint · VM 검증 | 역할 이름… → **권한 이름…** |
| 검증 doc 해당 줄 | [로그인_권한_P1P2_화면검증.md](docs/2026-11-25/로그인_권한_P1P2_화면검증.md) · [로그인_권한_남은작업.md](docs/2026-11-23/로그인_권한_남은작업.md)의 「역할 관리」만 **권한 관리**로 맞춤 |

## 건드리지 않음
- `RolesAdminScreen` / `AppPane.roles` / 도메인 `Role` / generated proto
- 계정 관리 화면의 「역할」 열·콤보·「역할을 고르세요」
- 삭제 확인 버튼 라벨이 아직 「지우기」면 이번엔 목록과 맞출 필요 없음(이전 작업 범위 밖이면 제목·본문만)

## 복잡한 코드 제거 및 금지
- 파일·클래스 이름 rename, 라우트 id 변경, 새 추상 계층 금지
- 생성 코드·proto 주석 수정 금지
- 범위 밖 문서·프롬프트 일괄 치환 금지(위 검증·남은작업만)
