# 계정·역할 목록 조회·초기화 제거

## 목표
계정 관리·역할 관리 목록에서 필터가 없는데도 보이는 **조회·초기화** 버튼을 없앤다. 목록은 화면 진입 시 기존처럼 `load()`로 채운다.

## 먼저 읽을 것
- [accounts_admin_screen.dart](lib/src/presentation/features/account_admin/accounts_admin_screen.dart) `CatalogLookupFrame` `filters` (약 51–63행)
- [roles_admin_screen.dart](lib/src/presentation/features/account_admin/roles_admin_screen.dart) 동일 구간

## 현재 상태
- 두 화면 모두 `filters: [CatalogLookupFilterActions(onQuery/onReset: viewModel.load)]`만 두어 조회·초기화가 같은 `load`를 부른다.
- 실제 필터 입력은 없다. `LookupTableHeader`의 「+ 새 계정/역할」과 진입 시 `..load()`는 그대로다.

## 바꿀 것
1. 계정·역할 화면에서 `CatalogLookupFilterActions` 항목을 빼고 `filters: const []`로 둔다.
2. `CatalogLookupFrame`·`CatalogLookupFilterActions` 공용 위젯, 서비스 토큰 화면은 수정하지 않는다.

## 복잡한 코드 제거 및 금지
- 공용 프레임 API를 바꾸거나 빈 Wrap 레이아웃을 리팩터하지 않는다.
- 서비스 토큰·다른 카탈로그 조회 화면은 건드리지 않는다.
- 범위 밖 스타일·이름 정리를 하지 않는다.

## 완료 확인
- `./scripts/agent_check.sh` 통과
- 계정·역할 목록에 조회·초기화 버튼이 없다
- 테이블 헤더·새 만들기·목록 로드는 유지
