# 로그인·권한 P1+P2 (비밀번호·계정관리)

## 목표
로그인한 사용자가 셸에서 비밀번호를 바꿀 수 있게 하고, `account.manage` 권한이 있으면 계정·역할·서버 연동 토큰을 관리하는 셸 메뉴·화면을 연다. 서버 로그인 검사 전에 README §2의 Auth/Account 관리 화면 공백을 메운다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md` (워킹 트리 밖 가이드라인만 읽기)
3. `docs/2026-11-23/README.md` §2, `docs/2026-11-23/로그인_권한_남은작업.md`, `protos/mediatag/auth/v1/auth.proto`
4. `remote_auth_repository.dart`, `auth_session_view_model.dart`, `shell_screen.dart` `_AuthSessionActions`, `media_tag_data_source.dart`, `app_route_state.dart`, `app_coordinator.dart`, worker_lookup 목록·생성 다이얼로그 패턴

## 현재 상태
- Login/Logout/GetCurrentAccount·Bearer·401 됨. `ChangePassword` 호출·UI 없음.
- `AccountServiceClient` 미배선. 계정/역할/토큰 화면·라우트·pane 없음. `hasAccountManage` getter만 존재.
- 권한 버튼 숨김은 `timeline.edit`→멀티모달만. P3 대상.
- 하드코드 `geosoft`/`user` 앱 소스에서 제거됨(재점검만).

## 바꿀 것

### P1 — ChangePassword
1. `AuthRepository`에 `changePassword(currentPassword, newPassword)` 추가. `RemoteAuthRepository`가 `AuthService.ChangePassword` 호출.
2. 새 비밀번호는 UTF-8 **바이트** 길이 8~72 검증(클라). 확인 칸 불일치·현재 비번 빈 값 거부.
3. `AuthSessionViewModel`(또는 얇은 UseCase+VM)에 `changePassword` — `PermissionDenied`→현재 비번 오류, 그 외 Connect 오류 메시지.
4. `shell_screen.dart` `_AuthSessionActions`: 표시명 옆에 **비밀번호 변경** 버튼 → `ContentDialog`(현재/새/확인). 성공 시 「다른 세션은 끊깁니다」안내 후 닫기. 로그아웃 버튼 유지.

### P2 — AccountService 관리
1. `MediaTagDataSource`에 `AccountServiceClient accountService` 추가(기존 Transport).
2. `RemoteAccountRepository`(한 파일) — List/Create/Update Accounts, ListPermissions, List/Create/Update/Delete Roles, List/Create/Revoke ServiceTokens. proto FieldMask를 Update에 맞게 채운다.
3. Domain 엔티티 최소: AccountRow, RoleRow, PermissionRow, ServiceTokenRow(+발급 시 one-shot token 문자열). 새 추상 계층·팩토리 금지.
4. Presentation `features/account_admin/`:
   - **계정 관리** 목록: login_name, display_name, role_name, inactive. 만들기 다이얼로그(login_name·display_name·role·password). 행에서 display_name·role·inactive·비밀번호 재설정(`account.manage`면 자기 계정 포함 역할·막기 변경 가능; 서버 거절 시 오류 표시).
   - **역할 관리** 목록: 이름·설명·권한 수. 만들기/고치기에서 `ListPermissions` 체크 목록. 삭제(사용 중이면 서버 FailedPrecondition 메시지).
   - **서버 연동 토큰** 목록: name, created_at, revoked_at, last_used_at. 발급(이름) → **원문 한 번만** 다이얼로그에 복사 가능 텍스트. 폐기 확인 후 Revoke.
5. 셸: `account.manage`일 때만 그룹 **계정** 아래 세 메뉴. `AppPane`에 `accounts` / `roles` / `serviceTokens`, 경로 `/accounts` `/roles` `/service-tokens`. coordinator·router·pane index 연동. 권한 없으면 메뉴 숨김(진입 URL이면 수집 모니터링으로).
6. Fluent 기존 lookup 목록·다이얼로그 톤 유지. 새 카드 UI·디자인 시스템 도입 금지.

### 문서·점검
1. `geosoft`/`user`/임시 비밀번호 문자열 잔여 grep 후 없으면 문서에 체크.
2. `로그인_권한_남은작업.md`에서 ChangePassword·계정·역할·토큰·셸 메뉴 항목 체크. P3~P5는 그대로 둠.

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
