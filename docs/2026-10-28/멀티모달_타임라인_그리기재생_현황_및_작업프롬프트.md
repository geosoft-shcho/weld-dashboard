## 2. 수정 방향 (우선순위)

가이드 §9.4 순서 + 앱이 이미 가진 멀티 모니터를 존중한다.

### P0 — 재생·시간축 정합 (회귀·정확도)
1. **단일 `T` 원칙 문서화·코드 정리**: playhead가 유일한 타임라인 시계. 파일 `timeupdate`는 포커스 영상 추종용으로만, 다른 트랙/`T`를 덮어쓰지 않게 규칙 고정.
2. **클립 배속 × (타임라인 배속)** → `playbackRate`. 타임라인 배속 UI(1 / 0.5 / 2…) 추가. 저장하지 않음.
3. **범위 밖 rate**: 가이드대로 재생 대신 `currentTime` 스텝(또는 명시적 폴백 로그). `supportedVideoPlaybackRate` 동작 재검토.
4. **`asset_start_time_ns`·`video.duration` 금지** 경로 점검(표시·끝 판정은 Asset 길이).

### P1 — 미리보기·편집 (가이드 「먼저」)
5. **고른 트랙 1개 = 주 미리보기** 모델을 모니터 0개일 때 가이드에 맞추고, 모니터 N개는 “나중/확장”으로 유지하되 포커스 칸만 `T`를 민다는 현재 규칙을 가이드 부록으로 명시.
6. **자르기(기본) vs 길이만 바꾸기(보조키)** — UpdateClip에 timeline·source 동시/단독 반영.
7. **소스 막대(읽기+손잡이 1차)**: Asset 길이 기준, 쓰는 구간 표시, Properties와 연동. 소스 보기 전환은 2차.
8. kind별 스테이지: 최소 **빈 상태 문구 kind별** + 이미지 1종. PDF/포인트클라우드는 후속.

### P2 — 가이드 「나중」·품질
9. 나누기, 소스 밀기, 배속 1 되돌리기.
10. 시점·수치 태그 그리기.
11. 패스 창/`pass_id` 확대, 패스 띠.
12. mkv → 짝 mp4 안내.
13. 레인 상시 미니 파형(현재 펼침 차트와 역할 정리).

### 비범위 (이 프롬프트 묶음)
- proto 변경, 서버 자동 배치 로직 변경.
- 가이드 MD 본문 전면 개편(앱 확장은 부록 한 절만 제안).
- 커밋/푸시(요청 시).

## P0 작업 목록
1. playhead(`T`) 단일 시계 규칙: 어떤 콜백이 `T`를 쓰는지 주석+코드로 고정. 비포커스 모니터 칸은 `T`를 밀지 않음(현행 유지·회귀 테스트 포인트).
2. 타임라인 배속 상태(기본 1) + UI(보드 툴바 또는 스테이지). `playbackRate = 타임라인배속 × 클립배속`.
3. `clip_file_position` / seek / ended 판정이 `video.duration`이 아니라 `asset_duration_ns`+`asset_start_time_ns`인지 전수 확인·수정.
4. 브라우저 rate 범위 밖·클립 배속 0: 가이드 §6에 맞게 스텝 시킹 또는 동등 폴백(소리 off). 단순 `return 1`만으로 끝내지 말 것.

- [x] `T` 단일 시계 주석 + 비포커스 무시 + 스텝 시킹 중 파일 시계 무시
- [x] 타임라인 배속 0.5/1/1.5/2 순환 UI(보드 헤더) · `playbackRate = timeline × clip`
- [x] seek/끝 판정에 `contentEndMs`(asset 축) 우선, `video.duration` 폴백만
- [x] rate 0·범위 밖 → ViewModel 타이머로 `T` 진행 + 플레이어 스텝 시크·음소거

- [ ] 클립 끝 드래그 = 자르기(소스 연동). 보조키 = 길이만 바꾸기(소스 고정, 배속 변경).
- [ ] 소스 막대 1차(고른 클립, Asset 길이, 사용 구간, 손잡이→UpdateClip source).
- [ ] Properties에 클립 배속 읽기 전용 표시.

## 검증
- 첫 시각≠0 영상: 타임라인 `T` ↔ currentTime = 첫시각 + Asset축 (가이드 §5.1 숫자로 수동 확인).
- 소스 길이 ≠ 클립 길이: 배속 라벨·playbackRate 일치.
- 겹침 트랙: 줄 나누기 유지, 미리보기(또는 포커스 모니터)는 고른/최신 clip_id 규칙.
- 모니터 1~4: 포커스만 시계, `T` 공유.
- `flutter analyze` 해당 경로 치명 오류 없음.

## 완료 기준
- P0 체크리스트 통과.
- 선택한 P1이 가이드 절 번호와 코드 주석으로 연결됨.
- 남은 갭은 §2 P2로 이 문서에 남겨 두거나 PR 설명에 적음.

## 4. 한 줄 요약

앱은 **시간 변환·줄 나누기·클립 배속·멀티 모니터·타임라인 `T` 시계(클립 끝 후에도 span까지)·타임라인 배속·rate 스텝 시킹**까지 가이드 핵심을 상당 부분 갖췄고, **단일 미리보기 kind·소스 막대·자르기/길이분리**가 다음 구현 축이다.
