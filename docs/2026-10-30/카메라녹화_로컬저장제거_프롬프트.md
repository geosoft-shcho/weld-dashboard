# 카메라 녹화 로컬 저장 제거

## 목표
카메라 녹화 패널에서 브라우저 로컬 다운로드(영상/음성 저장)를 제거하고, 서버 업로드 API만으로 저장되게 한다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md`
3. `lib/src/presentation/features/video_multimodal/widgets/camera_recording_dialog.dart`
4. `lib/src/presentation/features/video_multimodal/camera_recording_view_model.dart`
5. `lib/src/domain/use_cases/download_camera_recording_file_use_case.dart`
6. `lib/src/domain/repositories/camera_recording_repository.dart`
7. `lib/src/data/repositories/browser_camera_recording_repository.dart`
8. `lib/src/presentation/core/di/locator.dart` (CameraRecordingViewModel 등록)
9. `lib/src/data/datasources/browser_file_download_web.dart` / `browser_file_download_stub.dart`
10. 없음 (별도 계약·화면안 없음)

## 현재 상태
- 정지 후 `영상 저장`/`음성 저장`이 `_downloadCameraRecordingFileUseCase`로 브라우저에 파일을 내려받는다.
- `녹화 파일 업로드`는 `_uploadAssetUseCase`로 서버에 올린다.
- `downloadBrowserFile`은 카메라 녹화 다운로드에서만 쓰인다.

## 바꿀 것
1. `camera_recording_dialog.dart`에서 `영상 저장`/`음성 저장` 버튼을 제거한다.
2. ViewModel에서 `canSaveVideo`/`canSaveAudio`, `didTapSaveVideo`/`didTapSaveAudio`, `_save`, download use case 의존을 제거한다.
3. `didTapStop` 안내 문구를 로컬 저장 유도에서 업로드 유도로 바꾼다. (예: 정지 후 업로드를 누르라는 안내)
4. `DownloadCameraRecordingFileUseCase` 파일과 locator 주입을 제거한다.
5. Repository의 `downloadFile`과 구현을 제거한다.
6. 호출처가 없어진 `browser_file_download_web.dart` / `browser_file_download_stub.dart`를 제거한다.
7. 업로드·미리보기·시작/정지·재시도 흐름은 유지한다.

## 유지할 것
- `didTapUpload` 서버 업로드·후처리·타임라인 배치
- 시작/정지/다시 시도/최소화·닫기
- prepare/start/stop/release use case

## 이번 작업에서 만들지 않음
- 업로드 API·TUS 변경
- 새 저장 UI·자동 업로드
- Assets Import 연결
- 테스트·문서 대정리

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.

## 완료 확인
- 패널에 영상/음성 저장 버튼이 없다.
- 정지 후 안내가 업로드를 가리킨다.
- 로컬 다운로드 use case·repo 메서드·browser_file_download 파일이 없다.
- 녹화 파일 업로드로 서버 저장이 된다.
