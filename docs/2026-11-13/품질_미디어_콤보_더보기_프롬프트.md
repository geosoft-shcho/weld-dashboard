# 콤보 안 더보기

## 목표
미디어 선택 ComboBox 드롭다운 안에 **더보기** 항목을 두고, 선택 시 `didTapLoadMoreJobMedia`로 다음 `ListAssets` 페이지를 이어 받는다. 콤보 옆 별도 버튼은 제거한다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md`
3. `lib/src/presentation/features/quality_issue/widgets/quality_media_host.dart` (`_MediaStrip` ComboBox·옆 Button)
4. `lib/src/presentation/features/quality_issue/quality_issue_view_model.dart` (`didTapLoadMoreJobMedia`)
5. 계약·화면안: 없음

## 현재 상태
- `_MediaStrip`이 ComboBox와 옆 `Button('더보기')`를 Row로 배치
- `hasMoreJobMedia`일 때만 옆 버튼 표시, `onLoadMoreJobMedia` 호출
- entries 비고 token만 있으면 안내 문구 + 옆 버튼

## 바꿀 것
1. `quality_media_host.dart` `_MediaStrip`만 수정 (VM·repo·screen props 유지)
2. 옆 `Button` 제거
3. ComboBox `items` 끝에, `hasMoreJobMedia`이면 sentinel 값(예: `__load_more__`)인 `ComboBoxItem` 추가 — 라벨 `더보기`, 로딩 중이면 ProgressRing 또는 `불러오는 중…`
4. `onChanged`: sentinel이면 `onLoadMoreJobMedia`만 호출하고 `onSelect`하지 않음 (선택값 유지). 그 외는 기존 `onSelect`
5. entries 비고 `hasMoreJobMedia`이면 안내 Text 대신 ComboBox만 (더보기 항목만) 표시. entries도 token도 없으면 `미디어 없음` 유지

## 유지할 것
- `hasMoreJobMedia` / `isLoadingMoreJobMedia` / `didTapLoadMoreJobMedia` API
- pageSize 50·캐시 append·pass 필터
- 미디어 선택·PDF/영상 호스트
