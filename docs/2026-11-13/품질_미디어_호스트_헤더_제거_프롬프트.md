# 품질 미디어 호스트 헤더 제거

## 목표
미디어 선택 콤보가 이름·종류를 보여 주므로, PaperScanHost·QualityVideoHost의 중복 헤더(종류 뱃지 + displayName)를 제거한다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md`
3. `lib/src/presentation/features/quality_issue/widgets/paper_scan_host.dart`
4. `lib/src/presentation/features/quality_issue/widgets/quality_video_host.dart`
5. `lib/src/presentation/features/quality_issue/widgets/quality_media_host.dart` (호출부 displayName)
6. 계약·화면안: 없음

## 현재 상태
- 콤보에 선택 미디어 라벨이 있다.
- 각 호스트가 상단에 페이퍼 원본/현장 영상 뱃지와 displayName을 다시 그린다.
- unavailable 슬롯에도 같은 종류 라벨 헤더가 있다.

## 바꿀 것
1. `PaperScanHost`: 헤더 Row(뱃지+displayName)와 unavailable 헤더 컨테이너 제거. 뷰포트·PDF만 남긴다. `displayName` 인자·`paperScanDisplayName`이 호스트 전용이면 함께 제거.
2. `QualityVideoHost`: 동일. `displayName`·`qualityVideoDisplayName` 호스트 전용이면 제거.
3. `quality_media_host.dart`: 호스트에 넘기던 `displayName:` 인자 제거.

## 유지할 것
- 콤보·더보기·PDF/영상 뷰포트 높이 540
- 미디어 선택·재생·PDF 동작

## 이번 작업에서 만들지 않음
- 콤보 UI 변경
- 새 레이아웃·디자인 시스템

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.

- 콤보·PDF/영상 재생은 유지된다
