## 현재 상태
- `_ActionIcon`은 `Tooltip` + `IconButton`만 쓴다. 문구는 호버 시에만 보인다.
- 헤더·데이터 바로가기 열 flex는 10이고, 데이터 영역은 flex 90이다.

## 바꿀 것
1. `_ActionIcon`을 아이콘+`Text`(fontSize 12) `Button`으로 바꾼다. 라벨은 기존 tooltip 문자열을 쓴다.
   - 작업 상세 / 패스 프로파일 / 품질 이슈 / 비디오 멀티모달
2. 라벨이 보이므로 `Tooltip`은 제거한다. `onPressed`·권한 분기는 유지한다.
3. 바로가기 열을 넓힌다: 헤더·데이터 `바로가기` flex `10` → `28`, 데이터 묶음 flex `90` → `72`. 데이터 칸 flex를 `13,13,11,8,11,5,5,6`(합 72)로 맞추고 헤더도 동일하게 맞춘다.
