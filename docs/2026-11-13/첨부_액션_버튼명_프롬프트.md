# 첨부 탭 액션 버튼명

## 목표
`job_attachment_tab.dart` 첨부 행 두 액션에 버튼명을 붙인다. 라벨은 **작업상세**, **에셋 제거**로 둔다(기존 툴팁「에셋 상세」「에셋 떼기」를 대체).

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md` (가이드라인 저장소는 워킹 트리 밖에서 읽기만)
3. `lib/src/presentation/features/job_lookup/widgets/job_attachment_tab.dart`
4. 없음

## 현재 상태
- 액션 열에 `IconButton`+`Tooltip`만 있어「에셋 상세」「에셋 떼기」는 호버 시에만 보인다.
- `_kAttachmentColActions`는 72이다.

## 바꿀 것
1. `IconButton`+`Tooltip`을 `Button`으로 바꾼다. 자식은 `Row(mainAxisSize: min)`에 기존 아이콘 + 짧은 `Text` 라벨.
2. 첫 버튼 라벨 `작업상세` — `didTapOpenAssetDetail` 유지. 둘째 `에셋 제거` — `_didTapDetach` 유지. `_isWorking`/빈 assetId 비활성 유지.
3. `_kAttachmentColActions`를 두 라벨 버튼이 들어가도록 늘리고, 헤더「기능」열 너비와 맞춘다. 고정 36폭 `SizedBox`는 제거한다.

## 유지할 것
- Detach ContentDialog·ProgressBar·패스 콤보 등 나머지 첨부 탭 동작

## 이번 작업에서 만들지 않음
- 네비게이션 대상 변경(에셋 상세 → 작업 상세 화면 등)
- 새 공용 액션 버튼 위젯 파일

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
