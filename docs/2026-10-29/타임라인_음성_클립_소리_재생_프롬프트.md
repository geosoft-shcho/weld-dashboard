# 타임라인 음성 클립 소리 재생

## 목표
타임라인 재생 중 `T`를 덮는 음성 클립의 `playbackUrl`을 just_audio로 재생해 소리가 나게 한다.

9. 계약·화면안: 없음

## 현재 상태
- `AudioClipChart`는 파형·탭 seek만 한다. just_audio가 없다.
- 타임라인 재생은 playhead 시계 + 영상 플레이어뿐이다.
- 가이드: 음성 클립은 고른 트랙과 상관없이 `T`에 걸리면 소리를 낸다. 그 경로가 없어 소리가 없다.

## 바꿀 것
1. ViewModel에 `T`를 덮는 audio 클립 하나(playbackUrl 있는 것, 겹치면 clipId 큰 쪽)와 파일 seek ms·배속 getter를 추가한다. 기존 `_playbackInput` / `fileSeekMillisecondsAt` / `playbackRateAt`을 재사용한다.
2. `MultimodalTimelineAudioPlayer` StatefulWidget: just_audio. wantsPlayback이면 play+seek, 아니면 pause. URL/클립 바뀌면 setUrl·seek. 드리프트 시 seek. 배속은 타임라인×클립(지원 범위만, 실패 시 1).
3. `MultimodalVideoStage`에 Offstage/크기 0으로 마운트한다. AudioClipChart·보드 UI는 시각만 유지한다.
4. 차트 펼침 여부와 무관하게 covering이면 소리 낸다.

## 유지할 것
- AudioClipChart waveform_pro
- 영상 플레이어·스텝 시킹 mute
- 작업 상세/에셋 JustAudio

## 이번 작업에서 만들지 않음
- 다중 음성 믹스
- 차트 안 재생 UI
- 영상 mute 정책 변경
- 로드 알고리즘 변경

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
