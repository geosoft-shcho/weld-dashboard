# 오디오 차트 높이 절반

## 목표
타임라인에서 audio 클립 차트를 펼쳤을 때 차트 영역 높이를 지금의 절반으로 줄여, 트랙이 덜 차지하게 한다. timeseries 펼침 높이는 그대로 둔다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md`
3. `lib/src/presentation/features/video_multimodal/widgets/timeline_board_helpers.dart`
4. `lib/src/presentation/features/video_multimodal/widgets/multimodal_timeline_board.dart`
5. 계약·화면안: 없음

## 현재 상태
- `TIMELINE_TIMESERIES_CHART_HEIGHT`는 240이다.
- `TimelineBoardRow.height`는 펼침이면 240, 아니면 레인 높이×laneCount이다.
- 펼친 audio·timeseries 클립 모두 `row.height`(240)를 쓴다.

## 바꿀 것
1. `TIMELINE_AUDIO_CHART_HEIGHT = 120` 상수를 `timeline_board_helpers.dart`에 추가한다.
2. `TimelineBoardRow`가 펼친 차트 높이를 구분한다. 펼친 클립이 audio면 120, timeseries면 기존 240을 쓰도록 `buildTimelineBoardRows`에서 설정한다.
3. `multimodal_timeline_board`의 펼침 `Positioned`는 계속 `row.height`만 쓰면 된다. audio 전용 분기 높이를 보드에 새로 두지 않는다.

## 유지할 것
- timeseries 펼침 높이 240
- AudioClipChart / TimeseriesClipChart 위젯·로드·탭 seek
- 접힌 레인 높이 `TIMELINE_TRACK_LANE_HEIGHT`

## 이번 작업에서 만들지 않음
- waveform_pro 스타일·API 변경
- 차트 내용·데이터 로드 변경
- timeseries 높이 변경

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
