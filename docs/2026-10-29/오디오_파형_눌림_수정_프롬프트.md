# 오디오 파형 눌림 수정

## 목표
타임라인 audio 차트 높이 120에서도 파형이 세로로 눌리지 않고, 가용 높이를 채우는 continuous 파형으로 보이게 한다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md`
3. `lib/src/presentation/features/video_multimodal/widgets/audio_clip_chart.dart`
4. `lib/src/presentation/features/video_multimodal/widgets/timeline_board_helpers.dart`
5. 계약·화면안: 없음

## 현재 상태
- `TIMELINE_AUDIO_CHART_HEIGHT = 120`으로 영역이 절반이다.
- `AudioClipChart`는 amplitudes를 그대로 넣고 `fillWaveform: false` continuous로 그린다.
- continuous는 중앙 대칭으로 `height/2`만 쓰므로, 피크가 1보다 작으면 높이가 줄수록 띠처럼 눌려 보인다.

## 바꿀 것
1. `AudioClipChart`에서 `WaveformData` 직전에 표시용 정규화(최댓값 → 1, 0이면 그대로).
2. `fillWaveform: true` (continuous 유지).
3. 높이 120·UseCase·탭 seek는 그대로. 정규화는 차트 표시만.

## 유지할 것
- `TIMELINE_AUDIO_CHART_HEIGHT` 120
- timeseries 펼침 높이·로드·탭 seek
- 작업 상세 파형

## 이번 작업에서 만들지 않음
- 높이 상수 변경
- timeseries·로드 알고리즘·작업 상세 파형 변경
- waveform_pro 패키지 교체

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
