# 오디오 클립 음성파형 차트

## 목표
타임라인에서 clip kind가 audio인 클립을 시계열과 같이 트랙 버튼으로 펼치면, 오디오 contentUrl의 확장자를 .wave로 바꾼 피크 파일을 받아 정적 진폭 그래프를 클립 자리에 보여 준다. 그래프를 탭하면 해당 시각으로 플레이헤드만 옮긴다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md` (가이드라인 저장소는 워킹 트리 밖에서 읽기만)
3. `lib/src/presentation/features/video_multimodal/video_multimodal_view_model.dart` (timeseries expand·load)
4. `lib/src/presentation/features/video_multimodal/widgets/multimodal_timeline_board.dart`
5. `lib/src/presentation/features/video_multimodal/widgets/timeline_board_helpers.dart`
6. `lib/src/presentation/features/video_multimodal/widgets/timeseries_clip_chart.dart`
7. `lib/src/presentation/features/work_detail/widgets/audio_waveform_data.dart`
8. `lib/src/data/datasources/remote/media_tag_data_source.dart` (`readContent`)
9. `lib/src/presentation/core/di/locator.dart`
10. 계약·화면안: 없음

## 현재 상태
- `TimelineClipKind.audio`: 보드에 막대·라벨만 있다. `chartExpandedClipId`·트랙 `show_chart`는 timeseries만 쓴다.
- `didSelectSampleClip`: timeseries만 차트 펼침. audio는 상세만 로드하고 시계열 차트를 접는다.
- `AudioWaveformData`: audiowaveform `.wave` 파싱·`sampledAmplitudes` 있음. 작업 상세는 `rootBundle`만 읽고, HTTP 음성은 피크를 안 받는다.
- `MediaTagDataSource.readContent`: 바이트를 받은 뒤 `utf8.decode`로 String만 반환한다. `.wave` 이진 파일에는 쓸 수 없다.
- 타임라인 음성 재생(just_audio)은 없다.

## 바꿀 것
1. `MediaTagDataSource`에 기존 GET과 같은 방식으로 `Uint8List`를 반환하는 바이트 읽기를 추가한다. `JobTimelineRepository` / `GetJobTimelineUseCase`에 같은 이름의 얇은 위임을 둔다. String `readContent` 동작은 유지한다.
2. `AudioWaveformData.assetPathFor`로 오디오 URL(또는 path)에서 `.wave` URL을 만들고, 바이트 읽기 → `AudioWaveformData.parse` → 샘플 진폭 목록을 만드는 로드 UseCase를 둔다(시계열 `LoadTimeseriesWaveformUseCase`와 같은 층). URL이 비거나 로드·파싱 실패면 빈 결과와 구분 가능한 오류를 반환한다.
3. ViewModel: audio 트랙 여부, 펼침 토글(선택 클립 → 플레이헤드 덮는 audio → 트랙 첫 audio), 펼침 시 `.wave` 로드, 접기, epoch로 낡은 응답 무시, 차트 탭 시 클립 로컬 ms → 플레이헤드 seek. 시계열과 동시에 하나만 펼친다(audio를 펼치면 timeseries 접기, 반대도 동일).
4. `didSelectSampleClip`에서 audio 선택 시 해당 클립 차트를 펼친다(timeseries와 동일).
5. 보드: audio 트랙에 시계열과 같은 `show_chart` 토글. 펼친 audio 클립 자리에 정적 진폭 차트 위젯(로딩·오류·진폭 막대/라인, 탭으로 seek). 기존 `AudioWaveformData`·타임라인 높이 상수 패턴을 재사용하고, 새 디자인 시스템·카드 UI는 쓰지 않는다.
6. DI에 로드 UseCase를 등록하고 ViewModel 생성부에 넣는다.
7. `.wave` URL 만들기·진폭 샘플(또는 로드 UseCase) 단위 테스트를 추가한다.

## 유지할 것
- 시계열 차트 펼침·CSV 로드·`WaveformChannelCharts` 동작
- 작업 상세/에셋 미리보기 `WorkDetailJustAudioStage` 재생 흐름
- audio 클립 생성·색·라벨·`contentUrl`/`playbackUrl` 매핑
- String `readContent` 호출부

## 이번 작업에서 만들지 않음
- 타임라인 안 just_audio 재생·일시정지
- 스펙트로그램
- 서버에 없는 `.wave`를 오디오 디코딩으로 대체하는 경로
- GetClip channels 매핑 변경
- IMU/시계열 채널 표시 개선

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.

## 완료 확인
- audio 트랙에서 차트 버튼을 누르면 해당 음성 클립 자리에 진폭 그래프가 펼쳐진다.
- 피크는 오디오 contentUrl의 `.wave` 형제 URL에서 온다.
- `.wave`가 없거나 실패하면 오류/빈 상태가 보이고 앱이 죽지 않는다.
- 그래프 탭 시 플레이헤드만 클립 구간 안으로 이동한다. 타임라인에서 음성 파일이 재생되지 않는다.
- timeseries 펼침과 동시에 열리지 않는다.
