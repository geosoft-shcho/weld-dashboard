# PipelineTrace 목록 패널 하단 토글

## 목표

가로 레일 `PipelineTraceGraphView`가 폭을 쓰도록, 우측 `_TraceListPanel`을 **그래프 아래**로 옮기고 토글로 펼침/접힘을 처리한다.

## 권장 레이아웃

1. **기본**: `Column` — 위 `Expanded(그래프)`, 아래 목록 영역.
2. **접힘 바**: 목록을 완전히 없애지 않고, 그래프와 목록 사이에 `여정 목록 ▴/▾` 바를 둔다. 바 탭·버튼으로 펼침/접힘.
3. **펼침 높이**: 고정 높이(~260). 그래프가 세로의 대부분을 유지하고, 목록은 스크롤한다.
4. 상단 칩 Row의 목록 토글 아이콘은 제거하고, 접힘 바로 통일한다(토글 위치가 목록 옆이라 의미가 분명함).

## 먼저 읽을 것

1. `pipeline_trace_tab_body.dart`
2. `pipeline_trace_graph_view.dart` (가로 레일)

## 현재 상태

- `Row(Expanded(그래프), SizedBox(width:380, 목록))` — 가로 레일 폭을 줄인다.
- 상단 `IconButton`으로 `_listPanelVisible` 토글.

## 바꿀 것

1. 본문을 `Column`: 그래프 `Expanded` + 접힘 바 + (펼침 시) 하단 목록 패널.
2. `_listPanelWidth` 제거, `_listPanelHeight`(약 260) 사용.
3. 접힘 바에서 펼침/접힘. 상단 칩 Row의 목록 토글 제거.
4. 클래스 주석을 “하단 목록 패널(토글)”로 수정.

## 유지할 것

- `_TraceListPanel`·헤더·큐 병목·ViewModel 연동
- 그래프 줌·팬·가로 레일

- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯이 있으면 그것을 쓴다.
