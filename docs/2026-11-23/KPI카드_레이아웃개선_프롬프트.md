# KPI 카드 레이아웃 개선

## 목표
적재·파일 등 이중 지표 카드에서 value/subtitle 혼동을 줄이고, 보이는 카드 개수만큼 가로폭을 균등 분할해 남는 여백 없이 배치한다.

## 먼저 읽을 것
- `lib/src/presentation/features/collection_monitoring/widgets/collection_kpi_cards.dart`

## 현재 상태
- title이 `A · B`인데 value는 A만 크게, subtitle에 B가 레이블 없이 붙어 혼동된다.
- `_cardWidth`가 최대 4열·320 clamp라 카드가 줄어도 오른쪽 빈 공간이 남는다.

## 바꿀 것
1. 카드 본문: 주 지표·부 지표에 짧은 레이블을 붙여 value/subtitle 역할을 구분한다(새 디자인 시스템·카드 UI 도입 금지, 기존 Fluent/테마만).
2. 가로 배치는 현재 카드 개수로 폭을 균등 분할(`Expanded` 또는 `(maxWidth - gap*(n-1))/n`, clamp로 남는 여백 만들지 않음). 좁으면 줄바꿈하되 한 줄의 칸도 같은 방식으로 채운다.
3. 제목은 주제만 짧게(파일/작업/용접/적재/임베딩…).

## 유지할 것
- KPI 데이터 바인딩·선택 동작·표시 조건(메타·코멘트 분모>0)

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
