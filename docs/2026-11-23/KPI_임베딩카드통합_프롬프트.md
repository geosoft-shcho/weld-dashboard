# KPI 임베딩 계열 카드 통합

## 목표
임베딩·메타·코멘트처럼 같은 성격(진행률 + 건수)의 KPI를 개별 카드가 아니라 **하나의 카드** 안에 구역으로 묶어 표시한다.

## 먼저 읽을 것
- `lib/src/presentation/features/collection_monitoring/widgets/collection_kpi_cards.dart`

## 현재 상태
- 임베딩 / 메타 / 코멘트가 각각 `_KpiCard`로 나뉘어 폭을 나눠 쓴다.

## 바꿀 것
1. 세 지표를 제목 `임베딩`인 단일 카드로 합친다. 구역: 클립(항상) · 메타(`attachedAssetCount > 0`) · 코멘트(`commentCount > 0`).
2. 구역마다 짧은 레이블 + 진행률 + `분자 / 분모`를 같은 스타일로 나란히(또는 세로 구분) 배치한다.
3. 카드 선택·탭은 기존 임베딩(`KpiCardKind.embedding`)만 유지. 메타·코멘트 단독 탭은 없음.
4. 고정 높이·균등 폭 규칙은 유지하되, 통합 카드 내용이 들어가게 높이만 필요 시 조정.

## 유지할 것
- 파일·작업·용접·적재 카드 구조
- summary 필드 바인딩

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
