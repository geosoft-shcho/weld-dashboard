# KPI 용접 커버리지·손실률 표시

## 목표
용접 카드에 종류별 커버리지 `%`와 `1 − covered/weld` 손실(미커버) `%`를 함께 표시한다.

## 정의
- 커버리지 = `covered_seconds / weld_duration_seconds`
- 손실률(이 화면) = `max(0, 1 − covered/weld)` — 용접 구간 중 해당 종류 기록이 덮지 못한 비율. 패킷 유실과 다름.
- 응답 `coverage`에 온 종류만 그린다. 분모 0이면 `—`.

## 바꿀 것
- 용접 카드 secondaryLabel: `커버리지 / 손실률`
- secondaryValue: `영상 83% / 17% · 센서 …` 형식(커버 / 손실)

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
