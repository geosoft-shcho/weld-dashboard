# PipelineTraceGraph 과확대 방지 · 탭 UI 통일

## 목표
`PipelineTraceGraphView`가 `fitWidth`로 **1배 넘게 확대**되지 않게 하고, 탭 바디(칩·목록)와 밀도·테두리가 어색하지 않게 맞춘다.

## 먼저 읽을 것
- `pipeline_trace_graph_view.dart` (FittedBox fitWidth)
- `pipeline_trace_tab_body.dart`

## 현재 상태
- `BoxFit.fitWidth`는 캔버스가 부모보다 좁으면 **확대**한다. 접힌 Stage일수록 노드·글자가 칩/목록보다 커 보인다.

## 바꿀 것
1. 스케일을 `min(1.0, parentWidth / canvasWidth)`로 제한(축소만, 확대 금지). 세로도 넘치면 `min`에 높이 비율을 넣어 영역에 맞춤.
2. 그래프 패딩·배경을 탭 바디와 맞춰 부자연스러운 확대 느낌을 줄인다(과도한 여백·이중 패딩 정리).

## 유지할 것
- 가로 레일·펼침·목록 높이 양보·ClipRect

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
