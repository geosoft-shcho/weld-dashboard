# 트랙 체크와 선택 행 제스처 분리

## 목표
라벨 행에서 체크박스는 트랙 켜기/끄기만, 행 본문 탭은 클립 선택(선택 시 수정·삭제 표시)만 하도록 제스처를 분리한다. 체크 해제(dim)된 트랙은 본문 탭으로 선택되지 않는다.

## 먼저 읽을 것
1. `lib/src/presentation/features/video_multimodal/widgets/timeline_board_track_labels.dart` `_trackLabelRow` / `_trackLabel`
2. `docs/2026-11-17/트랙_체크_비활성UI_프롬프트.md`
3. `docs/2026-11-17/트랙CRUD_라벨통합_프롬프트.md`

## 현재 상태 (겹침)
- `_trackLabelRow`가 클립 있는 행 전체를 `GestureDetector(onTap: onSelectClip)`로 감쌈.
- 체크박스는 안쪽 `GestureDetector`라 보통은 자식이 이기지만, 행 선택과 토글이 한 트리에 묶여 있음.
- `!row.isEnabled`일 때 본문은 `IgnorePointer`라 탭이 바깥 선택 GestureDetector로 통과 → 끈 트랙도 선택·하이라이트·수정/삭제 버튼이 뜸.

의미 구분:
- 체크 = `didTapToggleTrackVisibility` (행 유지 + dim)
- 행 선택 = 클립 선택 → `selectedServerTrack` → 수정/삭제 표시

## 바꿀 것
파일: `timeline_board_track_labels.dart`만.

1. `_trackLabelRow`에서 행 전체를 감싸는 `GestureDetector` 제거.
2. `_trackLabel`의 본문(`Expanded` 안)에만 선택 탭을 둔다.
   - 클립이 있고 `row.isEnabled`일 때만 `GestureDetector(onTap: onSelectClip)`.
   - 비활성 본문은 기존처럼 `Opacity` + `IgnorePointer`만 (선택 콜백 없음).
3. 체크박스·수정·삭제는 선택 GestureDetector 밖에 유지 (지금 CRUD 위치 유지).
4. 빈 트랙(클립 없음)은 선택 불가 유지.

## 유지할 것
- `selectedServerTrack` 기준 수정/삭제 표시
- 체크 → `didTapToggleTrackVisibility` / Tracks 메뉴와 동일 API
- 모니터·차트·mute 원형 버튼
- ViewModel·보드·툴바 변경 없음

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
