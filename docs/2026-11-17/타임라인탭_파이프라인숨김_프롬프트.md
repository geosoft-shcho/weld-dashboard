# 일자별 수집 타임라인 탭에서 파이프라인 UI 숨김

## 목표
「일자별 수집 타임라인」 탭에서는 `PipelineTraceTabBody` 및 위에 붙는 파이프라인 밴드가 보이지 않고, 타임라인만 보이게 한다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md` (가이드라인 저장소는 워킹 트리 밖에서 읽기만)
3. `lib/src/presentation/features/collection_monitoring/collection_monitoring_screen.dart`
4. 없음

## 현재 상태
- `currentIndex == 0`일 때만 `PipelineTraceTabBody`를 본문에 둔다.
- `currentIndex != 0`(타임라인)일 때 `PipelineTraceBand`를 탭 위에 보여 파이프라인 요약이 남는다.

## 바꿀 것
1. 타임라인 탭에서 `PipelineTraceBand` 표시를 제거한다. 타임라인 탭 본문은 `CollectionTimelineHost`만.
2. 적재 파이프라인 탭에서는 기존처럼 `PipelineTraceTabBody`만.
3. `./scripts/agent_check.sh` 통과.

## 유지할 것
- 탭 전환, 폴링 Provider, 타임라인/상태 테이블 분기

## 이번 작업에서 만들지 않음
- PipelineTraceBand 클래스 삭제(다른 용도 없으면 호출만 끊음), 폴링 중지 정책 변경

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
