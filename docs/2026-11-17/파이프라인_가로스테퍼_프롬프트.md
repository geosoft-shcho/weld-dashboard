# 파이프라인 가로 스테퍼 + 목록

## 목표
적재 파이프라인을 **가로 스테퍼(단계 큰 원 + 세부 점) + 여정 목록**으로 바꾸고, 스크롤을 최소화하며, 미선택 시에도 RUNNING·DONE·FAILED가 단계에 드러나고, 세부 이벤트 점은 전부 보이게 한다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md` (가이드라인 저장소는 워킹 트리 밖에서 읽기만)
3. `docs/2026-11-17/파이프라인_그래프_UI_권장안.md`
4. `lib/src/domain/entities/pipeline_trace_graph.dart`
5. `lib/src/presentation/features/collection_monitoring/widgets/pipeline_trace_graph_view.dart`
6. `lib/src/presentation/features/collection_monitoring/widgets/pipeline_trace_tab_body.dart`

## 현재 상태
- 단계별 **세로 열**에 세부 노드를 쌓는 그래프다.
- 사용자 확정: (1) A안 가로 스테퍼+목록, 스크롤 최소 (2) 미선택 시 가능한 모든 상태 표시 (3) 세부 점 전부 표시.

## 바꿀 것
1. 본화면 그래프를 **가로 한 줄 스테퍼**로 교체. 단계=큰 원, 세부=`pipelineStages` 노드 전부 작은 점(접기 없음). 단계 사이만 본선·활성 입자.
2. **스크롤 최소**: 스테퍼는 너비에 맞춰 `Expanded` 분배(가로 스크롤 지양). 세로 스크롤은 여정 목록만.
3. **미선택 집계**: visibleTraces 전체로 단계·세부 상태를 합친다(실패 > 진행/현재 > 완료 > idle). 선택 시에는 그 여정만.
4. 스테퍼 아래 **여정 목록**(파일·상태·현재 단계). 탭하면 선택·상세 패널. 칩·폴링·tool 숨김 규칙은 유지.
5. `pipeline_trace_graph_test` 보강 + `./scripts/agent_check.sh` 통과.

## 유지할 것
- ListTraces/GetTrace/GetQueue 폴링, Trace 단계·노드 ID, AppTheme, 칩 필터, 상세 패널
- pollSignature로 불필요 notify 스킵

## 이번 작업에서 만들지 않음
- 스윔레인(B안), 새 디자인 시스템·카드 UI, proto 변경, IoT 노드명

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
