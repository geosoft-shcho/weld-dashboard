# Tracks 메뉴 전체 체크박스·구분선

## 목표
Tracks 메뉴의 일괄 토글을 개별과 같은 체크박스+버튼명으로 바꾸고, 개별 목록과 구분선으로 나눈다.

## 바꿀 것
1. 원형 아이콘 일괄 버튼을 체크박스 + `전체` 라벨 행으로 교체. 탭 시 `didTapToggleAllTracks`.
2. 체크 상태: `areAllTracksEnabled`이면 `check_box`, 아니면 `check_box_outline_blank`.
3. 일괄 행과 개별 체크 목록 사이에 구분선.

## 유지할 것
- `didTapToggleAllTracks` / enable·disable API
- 개별 트랙 체크 행

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
