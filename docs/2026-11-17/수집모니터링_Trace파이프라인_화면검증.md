# (2026-11-17) 수집 모니터링 · Trace 파이프라인 그래프 UI — 화면 기획서

| 항목 | 값 |
|------|-----|
| 화면 | 수집 모니터링 (`collection_monitoring`) |
| 목적 | 레퍼런스처럼 **열 × 노드 × 상태색 × 흐름 점**으로 Trace 진행을 보여 준다 |
| UI 레퍼런스 | 첨부 파이프라인 모니터(단계 칩 · 세로 열 · 원형 노드 · 활성 경로 입자 · 줌) |
| API | `TraceService`(`ListTraces`·`GetTrace`) + 대기 시 `RunService.GetQueue` |
| 테마 | **현재 앱 다크** (`AppTheme.SURFACE` / `SURFACE_RAISED` / `INK`) |
| 구현 | **이 문서 확인 전에는 제품 코드를 고치지 않는다** |

---

## 1. 문제 정의

수집 모니터링에 장비·일자 타임라인은 있으나, **업로드 한 건이 받기→등록→후처리→임베딩 중 어디인지**를 한눈에 보는 파이프라인 뷰가 없다.  
레퍼런스의 단계 열·노드·상태색·흐름 입자 언어를 Trace 여정에 적용한다.

---

## 2. 목표

1. 파이프라인 **그래프**를 본화면으로 둔다 (표·워터폴만이 아님).
2. `ListTraces` / `GetTrace` / (대기 시) `GetQueue`로 칩·노드·선·대기열을 1~2초 폴링한다.
3. **RUNNING · DONE · FAILED**를 칩·목록·그래프에 포함한다.
4. 레이아웃: 탭 본문이 탭 영역보다 작아 남는 공간이 있으면 **탭 위에 파이프라인 위젯 밴드**를 둔다.
5. Redis/`/pipeline/live`는 쓰지 않는다.

---

## 3. 확정 결정 (구 오픈 이슈)

| # | 결정 |
|---|------|
| 1 | 측면 패널: **선택 전까지 접기(집계만)**. 여정 선택 시 상세 패널을 연다. 캔버스가 기본 전면. |
| 2 | **완료·실패 Trace 포함**. `ListTraces`는 status 비움(또는 RUNNING+DONE+FAILED 병합). 칩·목록·집계에 DONE/FAILED 반영. |
| 3 | `tool` 열: 현재 목록에 `tool.*` 이벤트가 있는 여정이 **한 건도 없으면 열·칩 숨김**. 생기면 표시. |
| 4 | **1차에 GetQueue**. 선택 여정(또는 active run)의 `run.queue`로 대기열을 찾아 **앞줄 run 목록**을 측면 상세에 표시. |
| 5 | **앱 다크 테마에 맞춤**. 레퍼런스 다크와 동일 계열. 별도 라이트 캔버스 없음. |

## 5. 레퍼런스 UI → 본 화면

IoT 노드명(PLC·MQTT·Data Lake…)은 **복사하지 않는다**. 가져올 것:

| 레퍼런스 | 본 화면 |
|----------|---------|
| 상단 컬러 칩 + `N개` | 단계 칩 + 그 stage에 머무는 Trace 수(상태별 구분 가능) |
| 칩 체크 | 열 보이기/숨김 |
| 세로 열 · 원형 노드 | Trace 단계·세부 이벤트 노드 |
| 회색 / 컬러 링 | idle / done / active / queued / failed |
| 점선 + 입자 | **선택된** 여정의 활성 경로 |
| + / − | 줌 |
| 마이크 등 | 범위 밖 |

## 6. 파이프라인 열 · 노드

| 열 ID | 칩 라벨 | 이벤트 | 액센트 |
|-------|---------|--------|--------|
| `receive` | 받기 | `receive.*` | 청록 |
| `register` | 등록 | `register.*` | 보라 |
| `postprocess` | 후처리 | `postprocess.*` | 주황 |
| `tool` | 도구 | `tool.*` | 남색 · **데이터 없으면 열 숨김** |
| `embed` | 임베딩 | `embed.*` | 보라 |
| `done` | 완료 | `done.*` | 초록 |

### 6.1 열 안 고정 노드

| 열 | 노드 ID | 라벨 |
|----|---------|------|
| 받기 | receive.started / screened / done | 받기 시작 · 검사 · 받기 완료 |
| 등록 | register.stored / asset / attached | 저장 · Asset · 첨부 |
| 후처리 | postprocess.run · props · duration · report · normalize · waveform · placed | 후처리 run · 속성 · … · 배치 |
| 도구 | tool.run | 도구 run |
| 임베딩 | embed.done | 임베딩 |
| 완료 | done.searchable / done.stored | 검색 가능 · 저장만 |

`receive.abandoned` · `register.duplicates` · 미지 name → 툴팁/배지만.  
연결: 열 왼쪽→오른쪽, 열 안 위→아래(또는 `at` 순).

## 7. 상태 → 노드 · 칩 · 선

### 7.1 노드

| 상태 | 조건 | 시각(다크) |
|------|------|------------|
| idle | 이벤트 없음 | `STATUS_OFF` 계열 회색 원 |
| done | 성공 이벤트 | 열 액센트 · 체크 |
| active | last_event가 여기 · RUNNING | 강한 링 · 펄스 |
| queued | run QUEUED | 주황 링 · 앞 건수 |
| running | run RUNNING / receive progress | 액센트 링 · % |
| failed | 이벤트·Trace 실패 | `STATUS_ERROR` · 툴팁 |
| skipped | skipped | 회색 + 건너뜀 |

### 7.2 칩 건수

`ListTraces`(완료·실패 포함, page_size 적절히) 후 `last_event` stage로 버킷:

- 받기/등록/후처리/도구/임베딩/완료 각각 건수  
- 칩에 **상태 힌트** 가능: 예) 후처리 `3` 중 실패 있으면 칩 테두리 경고색  
- 칩 체크 해제 → 열 숨김  
- `tool`은 버킷 합이 0이면 칩·열 자체 비표시

### 7.3 선 · 입자

골격선 항상(어두운 회색). 선택 여정 지나온 경로만 점선·입자. 실패 구간 빨강.

### 7.4 모드

| 모드 | 동작 |
|------|------|
| **집계(기본)** | 패널 접힘. 칩·열 집계만. 캔버스 전면. |
| **여정 선택** | 측면 패널 펼침: 요약 + GetTrace 이벤트 + **GetQueue 앞줄**. 경로·입자 표시. |
| 빈곳 클릭 | 선택 해제 → 집계 · 패널 접기 |

## 8. 화면 레이아웃

### 8.1 전체 골격

```text
[수집 모니터링]
  CommandBar
  KPI
  ┌─ (조건부) 탭 위 파이프라인 위젯 밴드 ─────────────────┐
  │  단계 칩 요약 · 미니 흐름(집계) · 선택 시 짧은 상태 한 줄   │
  └────────────────────────────────────────────────────────┘
  탭: 일자별 수집 타임라인 | 적재 파이프라인
  ┌─ 탭 본문 ──────────────────────────────────────────────┐
  │  타임라인 호스트  /  또는  전체 파이프라인 그래프 캔버스    │
  └────────────────────────────────────────────────────────┘
```

### 8.2 탭 위 파이프라인 위젯 밴드 (필수 규칙)

**조건:** 구현·표시할 **탭 본문 컨텐츠의 필요 높이가 탭 가용 영역보다 작아** 세로로 남는 공간이 있을 때.

| 동작 | 내용 |
|------|------|
| 밴드 표시 | 탭 행 **위**에 파이프라인 UI 위젯 영역을 추가해 남는 공간을 채운다 |
| 밴드 내용 | 단계 칩 + 축약 노드/흐름(집계). 데이터는 본문 그래프와 **같은 Trace 폴링 스냅샷** |
| 밴드 숨김·축소 | 탭 본문이 영역을 거의 채울 때(예: `적재 파이프라인` 전체 캔버스) → 밴드는 **접거나 칩 한 줄만** 남겨 본문에 높이를 넘긴다 |
| 다른 탭 | `일자별 수집 타임라인` 등에서 본문이 상대적으로 낮으면 밴드가 살아 있어 **탭을 바꿔도** 적재 진행 요약이 위에 보인다 |

높이 배분(안):

- 밴드 최소~최대 높이 클램프(예: 최소 칩 행 ~ 최대 뷰포트 35%)
- 나머지 = 탭 헤더 + 탭 본문 `Expanded`

측정: LayoutBuilder / 본문 intrinsic vs 가용 높이 비교 후 밴드 `flex` 또는 fixed height 결정.  
빈 여백만 두지 않는다.

### 8.3 탭 `적재 파이프라인` 본문

```text
[단계 칩 · 필터(전체/진행/완료/실패) · 새로고침]
┌─ 캔버스(줌) ────────────────────────────┬─ 측면(선택 시) ─┐
│ 열 · 노드 · 선 · 입자                      │ 여정 요약        │
│                                           │ GetTrace 상세    │
│                                           │ GetQueue 앞줄    │
└───────────────────────────────────────────┴─────────────────┘
                                         [+][−]
```

집계 모드에서는 측면 열 너비 0(접힘).

### 8.4 측면 패널 (선택 후)

| 구역 | 내용 |
|------|------|
| 요약 | file_name · trace_id · status · last_event · error |
| 진행 | progress% · run.wait(reason/ahead) |
| 이벤트 | GetTrace events · 구간 ms |
| **대기열 앞줄** | `GetQueue` → `queues` 중 `queue == trace.run.queue` → `runs`를 오래된 순으로 목록(앞 ahead건 강조). 내 run 하이라이트 |

빈 전체 목록: “표시할 적재 여정이 없습니다.”

### 8.5 조작

| 조작 | 동작 |
|------|------|
| 칩 체크 | 열 표시/숨김 |
| 노드·목록 클릭 | 여정 선택 · 패널 펼침 · GetTrace · (run 있으면) GetQueue |
| 캔버스 빈곳 | 집계 · 패널 접기 |
| 필터 | 전체 / 진행 / 완료 / 실패 (목록·칩 집계에 반영) |
| + / − | 줌 |
| 새로고침 | 폴링 1회 |
| Retry 등 | 1차 없음 |

## 9. 데이터 · 폴링

```text
수집 모니터링 화면(또는 파이프라인 밴드/탭) 활성
  → 1~2초 ListTraces(page_size=50~100, status 비움 → RUNNING+DONE+FAILED 포함)
  → 클라이언트에서 필터·stage 버킷
  → 선택 trace_id → GetTrace
  → 선택 Trace.run.queue 비어 있지 않으면 GetQueue
      → 동일 queue의 runs 앞줄을 패널에 바인딩
탭·화면 이탈
  → Timer 중지
```

도메인:

- `TraceRepository.listTraces` 추가  
- `ToolRunRepository.getQueue` 재사용(이미 RunService 연결됨)  
- 매퍼: events + 골격 → 노드 상태; last_event → 칩 버킷  
- **탭·밴드 공용** Trace ViewModel(보드 VM과 분리 권장)

## 13. 검증 체크리스트

- [ ] 탭 본문이 작을 때 **탭 위 파이프라인 밴드**가 생기고, 본문이 클 때 밴드가 접히거나 최소화된
- [ ] 기본은 집계·패널 접힘, 선택 시 패널+경로
- [ ] DONE/FAILED가 칩·목록·필터에 포함된다
- [ ] tool 열은 데이터 없을 때 숨긴다
- [ ] 선택·대기 시 GetQueue 앞줄이 보인다
- [ ] 다크 `AppTheme`만 쓴다
- [ ] TraceService(+GetQueue)만 조회한다
