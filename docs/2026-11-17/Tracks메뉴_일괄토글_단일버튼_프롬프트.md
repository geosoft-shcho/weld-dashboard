# Tracks 메뉴 일괄 토글 단일 버튼

## 목표
Tracks 메뉴의 전체 켜기/끄기를 아이콘 버튼 하나로 토글한다.

## 바꿀 것
1. ViewModel에 전체 활성 여부 getter와 `didTapToggleAllTracks()` 추가(또는 기존 enable/disable를 토글에서 호출).
2. 메뉴 UI는 아이콘 하나: 전부 켜짐이면 끄기 아이콘, 아니면 켜기 아이콘 + Tooltip.
3. 쓰이지 않게 된 이중 버튼 UI 제거. enable/disable 메서드는 토글이 재사용하면 유지.

## 유지할 것
- 개별 체크, 행 유지 dim
- Tracks 메뉴 오버레이

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
