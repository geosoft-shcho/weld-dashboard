# 세부 이벤트 전체 표시·동일 너비

## 목표
`_StageColumn` 세부 이벤트를 스크롤 없이 전부 보이게 하고, 같은 단계 안 `_DetailEventLabel` 너비를 동일하게 맞춘다. 잘리지 않도록 스테퍼는 내용 높이를 쓰고 목록(ListTraces) 영역은 줄어든다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md` (가이드라인 저장소는 워킹 트리 밖에서 읽기만)
3. `lib/src/presentation/features/collection_monitoring/widgets/pipeline_trace_graph_view.dart`
4. `lib/src/presentation/features/collection_monitoring/widgets/pipeline_trace_tab_body.dart`
5. 없음

## 현재 상태
- `_StageColumn`이 `Expanded`+`SingleChildScrollView`로 세부 목록을 스크롤한다.
- `_DetailEventLabel`이 `mainAxisSize: min`이라 라벨마다 너비가 다르다.
- 탭 본문이 스테퍼를 `SizedBox(height: 196)`으로 고정한다.

## 바꿀 것
1. `_StageColumn`에서 세부 목록 스크롤/`Expanded` 제거. `Column`+간격으로 `nodeIds` 전부 표시.
2. 세부 열 `crossAxisAlignment: stretch` + 라벨이 열 너비를 채우게 해 같은 단계 안 너비 통일. 텍스트 overflow는 ellipsis.
3. `PipelineTraceGraphView`는 내용 높이로 잡히게 `Expanded` 의존을 줄인다.
4. `pipeline_trace_tab_body`에서 스테퍼 고정 높이를 없애고 내용만큼 쓰게 하며, 여정 목록 `Expanded`는 남은 공간만 쓰게 한다(목록 영역 축소). 밴드 compact 높이도 내용에 맞게 조정.
5. `./scripts/agent_check.sh` 통과.

## 유지할 것
- 라벨 문구·상태색·pulse·탭 선택
- 칩·GetTrace 폴링

## 이번 작업에서 만들지 않음
- 접기, 도메인 변경, 새 파일

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
