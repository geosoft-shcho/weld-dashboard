# 타임라인 보드 라벨 열 정리

## 목표
`multimodal_timeline_board.dart`의 `_filled`에서 라벨 위젯 인라인 구성을 `_tracks`와 같이 `_trackLabels(rows)`로 빼 관리를 단순화한다. 체크박스는 아이콘 탭만 켜기/끄기, 라벨 행(체크 제외) 탭은 클립 선택으로 수정·삭제를 켠다.

## 먼저 읽을 것
1. `lib/src/presentation/features/video_multimodal/widgets/multimodal_timeline_board.dart` `_filled` / `_tracks`
2. `lib/src/presentation/features/video_multimodal/widgets/timeline_board_track_labels.dart`
3. `docs/2026-11-17/트랙체크_선택제스처_분리_프롬프트.md`

## 현재 상태
- `_filled`에 `TimelineBoardTrackLabels(...)`가 인라인이고, 우측만 `Expanded(child: _tracks(rows))`.
- 체크는 아이콘 `GestureDetector`, 선택은 본문(`Expanded`)에만 있음. 수정/삭제는 `selectedServerTrack`(선택 클립의 트랙)일 때 표시.
- 빈 트랙·클립 없는 행은 `onSelect` 없음 → 수정/삭제 불가(기존 `selectedServerTrack` 계약 유지).

## 바꿀 것
1. 보드: `_trackLabels(List<TimelineBoardRow> rows)` private 메서드 추가. 내용은 지금의 `TimelineBoardTrackLabels` 생성과 동일(`viewModel`, `rows`, `_trackLabelScrollController`, `_selectClip`).
2. `_filled`의 Row children을 `_trackLabels(rows), Expanded(child: _tracks(rows))`로 단순화.
3. 라벨(`timeline_board_track_labels.dart`):
   - 체크박스: 아이콘(+패딩)만 `didTapToggleTrackVisibility`. 행 선택과 겹치지 않음(유지·확인).
   - 라벨 행 선택 영역: 체크·수정/삭제 밖의 본문. 클립 있고 `isEnabled`일 때 `onSelectClip` → 하이라이트 + `selectedServerTrack`이면 수정/삭제 표시(유지·빈틈만 보강).
   - 선택 GestureDetector의 hit test를 `HitTestBehavior.opaque`로 두어 본문 빈 공간도 탭으로 선택되게 한다.

## 유지할 것
- `selectedServerTrack` / `didSubmitTimelineTrackName` / `didTapDeleteSelectedTimelineTrack`
- ViewModel에 트랙 전용 selection 필드 추가하지 않음
- `_tracks`·스크롤 동기·툴바·TrackMenu

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
