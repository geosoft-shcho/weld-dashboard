# 목록 테이블 공통화 방향

## 결론

관리 카탈로그(에셋·작업자·장비·공사)는 `CatalogLookupFrame` / `LookupTableHeader` / `CatalogLookupTable`을 공통으로 둔다.  
작업 이력(작업 관리 목록)은 `WorkHistoryTable`을 도메인 전용으로 유지한다. 하나로 합치지 않는다.

## 경계

| 화면 | 쓸 것 |
|------|--------|
| 에셋·작업자·장비·공사 목록 | CatalogLookup* |
| 작업 이력 목록 | WorkHistoryTable |

## 하지 말 것

- 작업 이력을 CatalogLookupTable의 string rows로 재작성
- WorkHistoryTable을 카탈로그 공통으로 승격
- “표니까 전부 하나로” 리팩터

## 실행

이 문서는 방향 확정만 기록한다. 제품 코드 변경 없음.
