# Catalog 필터 조회·초기화 (방향 A)

## 목표
`CatalogLookupFrame.filters`에 **조회**(현재 조건으로 즉시 재조회)·**초기화**(기본 조건으로 되돌린 뒤 재조회)를 둔다. 작업 이력식 pending/`조회 · 미적용`은 **금지**.

## 먼저 읽을 것
- `lib/src/presentation/core/widgets/catalog_lookup_table.dart` — `filters`는 `Wrap` 리스트
- `lib/src/presentation/features/asset_lookup/widgets/asset_lookup_filters.dart` · `asset_lookup_view_model.dart`
- `lib/src/presentation/features/equipment_lookup/equipment_lookup_screen.dart` · VM
- `lib/src/presentation/features/worker_lookup/worker_lookup_screen.dart` · VM
- `lib/src/presentation/features/project_lookup/project_lookup_screen.dart` · VM

## 현재 상태
- 네 화면 모두 필터 변경 시 debounce/즉시 `_reload`/`load`로 목록을 갱신한다.
- `didTapQuery` / `didTapReset` / pending 플래그는 없다.
- 에셋 필터는 `AssetLookupFilters` 안쪽 `Wrap`에 모여 있고, 나머지 세 화면은 `filters:`에 칸을 직접 나열한다.

## 바꿀 것
1. `catalog_lookup_table.dart`에 작은 액션 위젯 추가 (`onQuery` / `onReset`, 아이콘+「조회」`FilledButton` · 「초기화」`Button`). Frame API는 그대로 두고 `filters` 리스트에 끼운다.
2. 각 VM에 `didTapQuery` / `didTapReset`만 추가 (pending·미적용 문구·draft/applied 분리 없음).
   - **조회**: 검색 debounce 타이머 취소 후 `load()` 또는 `_reload(reset: true)`.
   - **초기화**: 필터를 기본값으로 되돌린 뒤 동일 재조회.
     - 에셋: kind/파일명/장비/작업/패스/후처리/미지정만 → 기본, 작업·패스 종속 상태 정리 후 `load`.
     - 장비: `queryText=''`, `includeInactive=false` → `_reload`.
     - 작업자: `queryText=''`, `kind=all`, `includeInactive=false` → `_reload`.
     - 공사: `queryText=''`, `emptyJobsOnly=false` → `_reload`.
3. UI 배치
   - 에셋: `asset_lookup_filters.dart` children 맨 끝에 액션 위젯.
   - 장비·작업자·공사: 각 screen의 `filters:` 맨 끝에 액션 위젯.

## 유지할 것
- 필터 변경 시 기존 자동 재조회(debounce 포함).
- `CatalogLookupFrame` / `CatalogLookupTable` / `LookupTableHeader` 계약.
- 작업 이력 커맨드바·pending 모델.

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
- **미적용→조회 / `doesHavePendingFilters` / `조회 · 미적용` 금지.**
