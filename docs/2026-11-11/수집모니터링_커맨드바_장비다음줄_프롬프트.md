# 수집 모니터링 커맨드바 장비 다음 줄

## 목표
수집 모니터링 `CollectionCommandBar`에서 **장비** 필터부터(작업자·공사·품목·작업·새로고침 주기·조회·초기화·새로고침)가 항상 다음 줄에 오도록 한다.

## 바꿀 것
1. [`collection_command_bar.dart`](lib/src/presentation/features/collection_monitoring/widgets/collection_command_bar.dart)를 `Column` 안 두 `CommandBar`로 나눈다.
   - 1줄: 일자·시작·종료·보기·기준·막대 단위
   - 2줄: 장비부터 조회·초기화·새로고침 (`top: 24` 유지)
2. sticky 바깥 Row는 다시 두지 않는다.

## 유지할 것
- 필터·액션 동작과 문구
- wrap 동작(각 줄 안)

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
