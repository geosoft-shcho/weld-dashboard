# 리소스 헤더 가로 스크롤 고정

## 목표
`CollectionResourceTimelineView`에서 행 라벨(`_buildResourceHeader`)이 가로 스크롤해도 왼쪽에 고정되어 보인다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md`
3. `lib/src/presentation/features/collection_monitoring/widgets/collection_resource_timeline_view.dart`
4. 계약: pub-cache `neon_timeline_flutter` `ResourceTimelineView` (`verticalController`, `timeHeaderHeight` 기본 48)

## 현재 상태
- `ResourceTimelineView`는 `resourceColumnWidth + canvas` 전체를 하나의 가로 `SingleChildScrollView` 안에 둔다.
- `_buildResourceHeader`가 가로 스크롤과 함께 밀린다.

## 바꿀 것
1. `_verticalController`를 만들고 `ResourceTimelineView`에 넘긴 뒤 `dispose`한다.
2. `resourceHeaderBuilder`는 레이아웃 폭만 유지하는 빈 칸(투명 `SizedBox.expand`)을 반환한다.
3. 기존 `Stack`에 왼쪽 고정 오버레이를 올린다.
   - 상단: `timeHeaderHeight`(48) · `resourceHeaderLabel` (패키지 코너 라벨 대체)
   - 하단: 같은 `itemExtent: 64` · 같은 `_verticalController`의 `ListView.builder`에서 기존 `_buildResourceHeader` 호출
   - 폭: `resourceColumnWidth`, 배경은 표면색으로 불투명 처리해 막대가 밑으로 비치지 않게 한다
4. 「지금」 마커·가로 스크롤 보정 로직은 유지한다.

## 유지할 것
- `didTapTimelineNode` / 더블탭, 이벤트 탭·선택, `pixelsPerMinute`·now line
- 패키지 포크·복사 금지
