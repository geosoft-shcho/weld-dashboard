# 에셋 필터 위젯 분리

## 목표
에셋 목록 필터 UI를 전용 위젯으로 분리하고, `asset_lookup_screen`은 그 위젯만 참조한다.

## 바꿀 것
1. `lib/src/presentation/features/asset_lookup/widgets/asset_lookup_filters.dart`에 필터·작업 선택 다이얼로그 이동.
2. `asset_lookup_screen.dart`는 `AssetLookupFilters`를 `CatalogLookupFrame.filters`에 넣어 참조만 한다.

## 유지할 것
- ViewModel·표·올리기 동작
- 필터 동작·문구

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
