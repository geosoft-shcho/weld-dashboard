# 에셋 상세 파일 내려받기

## 목표
업로드된 에셋 파일을 상세 화면에서 내려받을 수 있게 한다. 서버는 Download RPC가 없고 `Asset.content_url`(`/files/...`, Range 지원)로 바이트를 준다.

## 바꿀 것
1. 상세 `LookupDetailScaffold.actions`: `contentUrl`이 비어 있지 않으면 「내려받기」버튼을 「지우기」앞에 둔다. 누르면 `openBrowserUrl(asset.contentUrl)`.
2. 미리보기 `_canOpenUnsupported`: `contentUrl`이 있으면 종류와 관계없이 「내려받아 열기」를 보이게 한다(엑셀 안내와 맞춤).

## 유지할 것
- GetAsset/ListAssets·`contentUrl` 해석
- 미리보기·지우기 동작
- 새 Download RPC·저장 다이얼로그·blob 강제 저장은 넣지 않는다(브라우저가 URL로 열기/저장).

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.

## 완료 확인
- `./scripts/agent_check.sh` 통과
- 상세에서 contentUrl 있는 에셋에 「내려받기」가 보이고 누르면 파일이 열린다
- 엑셀 등 미지원 미리보기에도 「내려받아 열기」가 보인다
