# 타임라인 툴바 응답 건수 표기

## 목표
툴바 우측 건수 문구가 `_DrillCrumbs`로 조회한 `ListCollectionNodes` 응답 노드 레벨에 맞게 보이도록 한다. 장비 루트가 아니면 `대`를 쓰지 않는다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md`
3. `lib/src/presentation/features/collection_monitoring/widgets/collection_timeline_host.dart` (`_Toolbar` 267–271)
4. `lib/src/domain/use_cases/present_collection_nodes_use_case.dart` (`eventCount`, `equipmentRows`, `resourceHeaderLabel`)

## 현재 상태
- 툴바: `eventCount건 · equipmentCount대` 고정. `대`는 장비 단위인데 `equipmentCount`는 사실상 응답 노드(행) 수다.
- `PresentCollectionNodesUseCase`는 `resourceHeaderLabel`을 응답 노드 `path.level`(장비/작업자/공사/품목/작업/파일)로 둔다.
- 예: parent=ITEM → nodes=JOB 3개일 때 `3건 · 3대`처럼 잘못 읽힌다.

## 바꿀 것
1. `_Toolbar` 건수 문구를 응답 행 수(`timeline.equipmentCount`) + `resourceHeaderLabel` 기준 단위로 표시한다.
   - 장비 → `N대`
   - 작업자 → `N명`
   - 파일 → `N개`
   - 공사/품목/작업/그 외 → `N건`
2. 타임라인에 그려진 구간 수(`eventCount`)가 행 수와 다를 때만 `· N구간`을 덧붙인다.
3. 행이 0이면 `0` + 같은 단위(헤더가 비면 `건`).

## 유지할 것
- 줌·뷰 버튼, `_DrillCrumbs`, VM/조회/Present 로직(헤더 라벨 생성 방식 포함)

## 이번 작업에서 만들지 않음
- KPI·상태 테이블 문구, `CollectionResourceDepth` 하드코딩 수정, 새 엔티티 필드

- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
