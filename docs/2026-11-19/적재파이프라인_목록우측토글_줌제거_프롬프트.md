# 적재 파이프라인 목록 우측 토글 · 줌 제거

## 목표
캔버스 줌인/줌아웃을 제거하고, 노드·텍스트가 겹치지 않도록 그래프 영역을 확보한다. `PipelineTraceList`는 오른쪽 패널로 두고 토글 버튼으로 숨김/보임 한다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md` (가이드라인 저장소는 워킹 트리 밖에서 읽기만)
3. `lib/src/presentation/features/collection_monitoring/widgets/pipeline_trace_tab_body.dart`
4. `lib/src/presentation/features/collection_monitoring/widgets/pipeline_trace_graph_view.dart`
5. 없음

## 현재 상태
- `InteractiveViewer`로 줌/팬 가능.
- 목록·필터·선택 요약·큐 병목이 그래프 아래 고정 높이로 붙어 그래프 높이가 줄어든다.
- fit 스케일 시 셀이 작아져 노드·라벨이 겹칠 수 있다.

## 바꿀 것
1. `pipeline_trace_graph_view.dart`: `InteractiveViewer`/TransformationController 제거. viewport에 맞춰 열·행 간격을 나눠 배치하되 최소 셀 크기(겹침 방지)를 둔다. 최소보다 viewport가 작으면 그래프만 스크롤(줌 아님).
2. `pipeline_trace_tab_body.dart`: Expanded를 `Row(그래프 Expanded | 토글 | 우측 패널)`로 바꾼다. 우측 패널에 필터 헤더·`PipelineTraceList`·선택 요약·큐 병목을 넣는다. 토글로 패널 숨김/보임(기본 보임).

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
