# 현장 영상 displayName 서버 필드 사용

## 목표
현장 영상 헤더가 content URL basename 대신 서버 `Asset.fileName`(`QualityJobMedia.label`)을 보여 한글이 깨지지 않게 한다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md`
3. `lib/src/presentation/features/quality_issue/widgets/quality_video_host.dart`
4. `lib/src/presentation/features/quality_issue/widgets/quality_media_host.dart`
5. 계약·화면안: 없음 (Asset.fileName / QualityJobMedia.label 사용)

## 현재 상태
- `QualityVideoHost`는 `qualityVideoDisplayName(videoFile)`로 URL 마지막 segment만 씀
- 스트립에는 이미 `item.label`(= `fileName`)이 있으나 `QualityVideoHost`에 넘기지 않음

## 바꿀 것
1. `QualityVideoHost`에 optional `displayName` 추가. 비어 있지 않으면 사용, 비면 기존 `qualityVideoDisplayName(videoFile)` fallback (`PaperScanHost`와 동일 패턴).
2. `quality_media_host.dart` 호출부:
   - `_MediaStrip` video: `displayName: selected.label`
   - 레거시 탭 video: `displayName: selectedFile.displayName` (해당 경로에 서버 fileName이 없으면 URL fallback 유지)
3. 도메인/리포지토리 추가 변경 없음 (`QualityJobMedia.fileName` 이미 매핑됨)

## 유지할 것
- 재생·seek·뷰포트 구조
- `PaperScanHost` 쪽 기존 수정

## 이번 작업에서 만들지 않음
- 새 추상 계층, URL decode 전용 헬퍼
- 페이퍼/리포트 경로 재수정

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
