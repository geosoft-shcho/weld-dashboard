# 타임시리즈 차트 — 축 없는 파형 + 클릭 시 좌표 표시

## 목표
타임라인에 펼친 시계열 차트는 기본에 X/Y 축 없이 파형만 보이게 하고, 탭한 시각의 시간·전류·전압·속도·rpm 값을 공용 리드아웃 스트립으로 보여 준다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md` (가이드라인 저장소는 워킹 트리 밖에서 읽기만)
3. `lib/src/presentation/features/video_multimodal/widgets/timeseries_clip_chart.dart`
4. `lib/src/presentation/core/widgets/waveform_channel_charts.dart`
5. 없음 (별도 화면안 문서 없음; 확인된 계획: 베어 파형 + 공용 리드아웃)

## 현재 상태
- `timeseries_clip_chart.dart`: `WaveformChannelCharts`를 robot 시리즈만으로 표시. `selectedTimeMs`·`onTimeTapMs` 전달.
- `waveform_channel_charts.dart`: 채널마다 왼쪽 Y 눈금·아래 X(ms)·테두리. 탭 시 세로 커서 + `onTimeTapMs`.
- `video_multimodal_view_model.dart`: `didTapTimeseriesChartTime` → 클립 기준 시크.

## 바꿀 것
1. `WaveformChannelCharts`에 타임라인용 플래그(예: `showAxisTitles`, 기본 `true`)를 추가한다. `false`이면 Y/X SideTitles·두꺼운 축 테두리를 끄고, 패딩을 줄이며, 채널 라벨은 짧게(`전류`, `전압`, `속도`, `회전 속도`) 둔다. 품질 비교·패스 화면 기본은 유지한다.
2. `TimeseriesClipChart`에서 `showAxisTitles: false`로 호출한다.
3. `selectedTimeMs`가 있을 때 차트 위에 한 줄 리드아웃을 보여 준다. 형식 예: `1.234 s | I=… A | V=… V | v=… m/min | rpm=…`. 해당 시각(또는 최근접 점)의 robot 시리즈 값을 쓰고, 없으면 `—`.
4. 탭 → 기존 시크·커서 동작은 유지한다. 선택 해제는 이번 범위에 필수가 아니다.

## 유지할 것
- `didTapTimeseriesChartTime` / `_didSeekChartTime` 시크 흐름
- 품질 이슈·패스 프로필 화면의 `WaveformChannelCharts` 축 표시
- CSV 파서·로드 UseCase·ViewModel 차트 세션 로직

## 이번 작업에서 만들지 않음
- 드래그 구간 선택
- 선택 시 축을 다시 켜는 UI
- 채널별 플로팅 툴팁·확대 팝업
- ViewModel 선택 해제 API (필수가 아니면 생략)
- 새 추상 계층·새 차트 라이브러리

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
