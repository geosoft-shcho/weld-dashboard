# 패스 비교 지표 레이아웃

## 목표
패스 프로필 화면에서 기존 `PassCompareSummary` 채널×비교쌍 표를 없애고, 차트 아래에 **평균 차이**·**유사도** 두 항목만 자연스럽게 배치한다. 서버는 아직 없으므로 계산·API 연동 없이 UI만 둔다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md` (가이드라인은 워킹 트리 밖 읽기만)
3. `lib/src/presentation/features/pass_profile/pass_profile_screen.dart` (`_PassChartPane`)
4. `lib/src/presentation/features/pass_profile/widgets/pass_compare_summary.dart`

## 현재 상태
- `_PassChartPane`: 폭 ≥960이면 차트|요약 가로 배치, 아니면 차트 아래 요약.
- `PassCompareSummary`: `ChannelCompareStats`로 전류·전압·속도·회전의 평균/최대를 표로 표시.
- `ChannelCompareStats`는 board·use case·테스트에서도 쓰임 → **도메인/테스트는 유지**, 화면 요약 UI만 교체.

## 바꿀 것
1. **레이아웃** (`pass_profile_screen.dart`)
   - `_PassChartPane`은 차트(로딩·에러·배너 포함)만 담당.
   - ready `ListView`에서 `_PassChartPane`과 `PassCompareSummary`를 `Row`로 둔다 (차트 flex 8, 요약 flex 2, 간격 16).
2. **위젯** (`pass_compare_summary.dart`)
   - `ChannelCompareStats` 의존 제거.
   - 제목 `비교 지표` + 부제 `서버 미구현`.
   - 아래를 **표(Table)** 로 구성:

| 항목 | 설명 | 값 |
|------|------|-----|
| 평균 차이 | 아크 켜진 전체 구간의 명장 평균 대비 상대 평균이 얼마나 다른지 (예: 전류 +5.8A) | `—` |
| 유사도 | 두 파형 모양이 얼마나 닮았는지 (값이 높을수록 비슷) | `—` |

   - 기존 SURFACE_RAISED 패널·테두리·헤더 톤은 패스 화면과 맞게 유지. 새 카드/디자인 시스템 도입 없음.
3. **`_ChartSnapshot`**
   - `stats` 필드·동등성·`from`의 `ChannelCompareStats` 조립 제거.
   - board의 `compareStats`·domain·기존 테스트는 손대지 않음.

## 유지할 것
- 차트·레전드·비교 작업 콤보·품질 이슈 이동.
- `ChannelCompareStats` / `PassProfileBoard.compareStats` / 관련 테스트.

## 이번 작업에서 만들지 않음
- 서버 API·use case·평균 차이/유사도 실계산.
- 채널별·명장vs작업자/로봇 셀 값.
- quality_issue 쪽 동일 UI.

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
