# 시계열 차트 탭 — 시크 유지, 새로고침감 제거

## 목표
타임라인 시계열 차트에서 탭하면 playhead·영상·리드아웃만 그 시각으로 이동하고, 클립 재선택·detail 재로드·차트 교체 애니메이션으로 인한 새로고침감은 없앤다.

## 현재 상태
- 펼친 차트가 `GestureDetector(onTap: _selectClip)`로 감싸여 탭 시 `didSelectSampleClip` → 클립 시작 시크 + `_loadClipDetail` 가능.
- `LineChart` 기본 duration 150ms로 playhead 갱신마다 파형 보간.
- 탭 → `onTimeTapMs` → `_didSeekChartTime` → `didSeekToSeconds`는 유지할 동작.

## 바꿀 것
1. `clip.isChartExpanded` 분기에서 바깥 `GestureDetector(onTap: _selectClip)` 제거. `DecoratedBox` + 차트만.
2. 타임라인용(`!showAxisTitles`) `LineChart`에 `duration: Duration.zero`.
3. 펼친 `TimeseriesClipChart`에 `ValueKey(clip.clipId)`로 Element 재사용.

## 유지할 것
- `didTapTimeseriesChartTime` → 시크
- 호버 툴팁·인디케이터, 리드아웃
- 접힌 클립 선택/`didSelectSampleClip`

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
