# 파형 차트 — 시분초·호버 공통 적용

## 목표
품질·패스 화면의 `WaveformChannelCharts`도 타임라인과 같은 공통 로직으로 X 시각을 `h:mm:ss`로 보이고, 호버 툴팁(t·y)을 켠다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md`
3. `lib/src/presentation/core/widgets/waveform_channel_charts.dart`
4. `lib/src/presentation/features/video_multimodal/timeline_playhead_clock.dart`
5. 없음

## 현재 상태
- 호버 툴팁·얇은 인디케이터: `showHoverTooltip = !showAxisTitles`라 품질/패스(축 있음)에서는 꺼짐.
- 품질/패스 커서·하단 축: `… ms`.
- 타임라인: 커서/리드아웃 시분초, 호버 툴팁 있음.

## 바꿀 것
1. `WaveformChannelCharts`에서 호버 툴팁을 축 표시와 무관하게 항상 켠다 (`showHoverTooltip = true`).
2. 점선 커서 라벨: `selectedTimeLabel`이 있으면 그것, 없으면 `formatPlayheadClock(selectedTimeMs/1000)` (품질/패스 ms 분기 제거).
3. 하단 X 축(축을 켤 때) min/max 라벨도 `formatPlayheadClock(value/1000)`.
4. 품질/패스 호출부는 공통 위젯만 바꾸면 되고, 화면별 중복 설정은 넣지 않는다.

## 유지할 것
- 축 표시/`showAxisTitles` 레이아웃(높이·패딩·테두리)
- 밴드 탭·`onTimeTapMs` 시크
- 타임라인 `selectedTimeLabel`(playheadLabel) 전달

## 이번 작업에서 만들지 않음
- 품질/패스 축 숨김, 리드아웃 스트립 추가
- `chartTimeNs` 이름 정리

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
