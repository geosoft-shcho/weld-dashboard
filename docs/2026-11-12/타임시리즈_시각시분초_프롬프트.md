# 타임시리즈 차트 시각 — 시분초 표기

## 목표
타임라인 시계열 차트의 점선 커서·리드아웃·호버 시간을 `1.234 s` 같은 소수 초가 아니라 타임라인과 같은 `h:mm:ss` 시분초로 보여 준다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md`
3. `lib/src/presentation/features/video_multimodal/timeline_playhead_clock.dart` (`formatPlayheadClock`)
4. `waveform_channel_charts.dart`, `timeseries_clip_chart.dart`, `multimodal_timeline_board.dart`
5. 없음

## 현재 상태
- 타임라인용 커서/리드아웃/호버: `toStringAsFixed(3) s`
- 타임라인 툴바 playhead: `formatPlayheadClock` → `h:mm:ss`

## 바꿀 것
1. 점선 커서·리드아웃: `viewModel.playheadLabel`(절대 작업 시각, 툴바와 동일) 사용.
2. 호버 툴팁 t=: 차트 X(클립 상대 ms)를 `formatPlayheadClock(x/1000)`로 시분초 표기.
3. 품질/패스(`showAxisTitles: true`) 커서 `… ms`는 유지.

## 유지할 것
- 시크·호버·축 숨김 동작
- `formatPlayheadClock` 헬퍼 (새로 만들지 않음)
