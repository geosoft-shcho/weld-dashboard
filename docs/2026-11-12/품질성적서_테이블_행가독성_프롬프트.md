# 품질 성적서 테이블 행 가독성·선택 표기

## 목표
품질 검사 결과 테이블에서 행이 한눈에 구분되고, 검사 테이블은 행을 눌러 PDF로 이동할 수 있음이 보이도록 한다.

## 먼저 읽을 것
- `lib/src/presentation/features/quality_issue/widgets/quality_results_tables.dart`
- `lib/src/presentation/core/themes/app_theme.dart` (`ROW_STRIPE`, `tableRowColor`)
- `lib/src/presentation/features/quality_issue/quality_issue_screen.dart` (`_QualityResultsPane`)
- `lib/src/presentation/features/work_history/widgets/work_history_table.dart` (행 색·hover 참고)

## 현재 상태
- `_InspectionTable`·`_JointTable`은 테두리만 있고 행 배경이 없다. 짝수 행 스트라이프 없음.
- 검사 행은 `_Body(onTap:)`로 선택되지만 커서·hover·선택 색이 없어 선택이 안 보인다.
- 이음부 테이블은 선택 없음.
- `AppTheme.tableRowColor`·`ROW_STRIPE`가 이미 있다.

## 바꿀 것
- `quality_results_tables.dart`
  - 검사·이음부 데이터 행에 `AppTheme.tableRowColor(index:)`로 짝수(1-based 홀수 index) 스트라이프.
  - 검사 테이블만: `selectedReportSetId`로 해당 보고서 행 선택 색, hover, click 커서, 행 끝 선택 힌트(아이콘 또는 짧은 문구).
- `quality_issue_screen.dart` `_QualityResultsPane`: `selectedReportSetId`를 테이블에 넘긴다.

## 넣지 말 것 / 건드리지 말 것
- ViewModel 선택 로직·PDF 페이지 변환 변경
- 이음부 행 선택 추가
- 새 테마 토큰·새 테이블 추상 계층
- 가이드라인 저장소 클론

## 복잡한 코드 제거 및 금지
- 한 동작을 위한 새 추상 계층·전략·팩토리·제네릭 헬퍼를 만들지 않는다.
- 새 상태관리·디자인 시스템·카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖 리팩터·이름 정리·스타일 통일을 하지 않는다.
- 기존 `AppTheme.tableRowColor`를 재사용하고 중복 색 계산을 새로 두지 않는다.

## 완료 확인

- 검사 행 hover·커서·선택(보고서) 색으로 선택 가능함이 보인다
- 이음부 행은 선택 UI가 없다
