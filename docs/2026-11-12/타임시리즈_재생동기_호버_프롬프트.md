# 타임라인 시계열 — 재생 동기화 + 호버 XY

## 목표
펼친 시계열 차트의 세로 커서가 타임라인 playhead와 같은 클립 상대 시각으로 움직이고, 호버하면 해당 지점의 X(시간)·Y(채널 값)를 보여 준다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md` (가이드라인 저장소는 워킹 트리 밖에서 읽기만)
3. `lib/src/presentation/features/video_multimodal/widgets/timeseries_clip_chart.dart`
4. `lib/src/presentation/core/widgets/waveform_channel_charts.dart`
5. `lib/src/presentation/features/video_multimodal/widgets/multimodal_timeline_board.dart` (차트 호출부)
6. 없음 (확인된 계획: durationMs maxX + 호버 툴팁)

## 현재 상태
- `timeseriesSelectedTimeMs`: playhead − clipStart → ms. 재생 틱 시 notify.
- 차트 커서: VerticalLine, 라벨 `… ms`, X 범위는 데이터 min/max만.
- 터치: FlTapUp만 시크. 호버 툴팁 없음.
- 리드아웃 스트립: selectedTimeMs(재생) 기준.

## 바꿀 것
1. 보드의 `durationMs`를 `TimeseriesClipChart`에 넘기고, `WaveformChannelCharts`에 `axisMaxXMs`(또는 동등)로 전달한다. `maxX = max(데이터 maxX, durationMs)`, `doesStartAtZero`와 함께 minX=0.
2. 타임라인용(`showAxisTitles: false`) 재생 커서 라벨을 `1.234 s` 형식으로 통일한다. 리드아웃은 재생 시각만 유지.
3. 타임라인용 `LineTouchData`: `handleBuiltInTouches: true` + 툴팁에 `t=… s` / `y=…`. `FlTapUpEvent`에서만 시크. 호버는 시크하지 않음.
4. 품질/패스(`showAxisTitles: true`)는 기존 탭·밴드·축 유지, 호버 툴팁 끔.

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
