# 타임시리즈 호버 인디케이터 크기

## 목표
타임라인 시계열 차트 호버 시 fl_chart 기본 세로선·점 크기를 줄여 세로선 1px, 점은 기본의 절반으로 보이게 한다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md`
3. `lib/src/presentation/core/widgets/waveform_channel_charts.dart`
4. 없음

## 현재 상태
- `showHoverTooltip`일 때 `handleBuiltInTouches: true`로 fl_chart 기본 인디케이터 사용 (선 4px, 점 radius 10).

## 바꿀 것
1. `LineTouchData.getTouchedSpotIndicator`를 타임라인 호버일 때만 지정한다. 세로선 `strokeWidth: 1`, 점 radius `5`(기본 10의 절반).
2. 품질/패스(`showHoverTooltip: false`)는 기존 동작 유지.

## 유지할 것
- 툴팁 문구, 탭 시크, 재생 VerticalLine

## 이번 작업에서 만들지 않음
- 재생 커서 스타일 변경, 품질 화면 터치 인디케이터

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
