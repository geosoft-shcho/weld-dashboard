# 페이퍼 원본 displayName 서버 필드 사용

## 목표
페이퍼 원본 헤더에 URL 파일명 대신 서버 `fileName`(사용자용 파일 이름)을 보여 한글이 깨지지 않게 한다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md`
3. `lib/src/presentation/features/quality_issue/widgets/paper_scan_host.dart`
4. `lib/src/presentation/features/quality_issue/widgets/quality_media_host.dart`
5. `lib/src/domain/entities/quality_job_media.dart`, `quality_result_report.dart`, `report_set.dart`
6. `lib/src/data/repositories/remote_report_set_repository.dart`
7. 계약·화면안: 없음 (Asset.fileName 사용)

## 현재 상태
- `PaperScanHost`는 `scanFile`만 받고 표시명은 URL basename
- `_MediaStrip`은 `PaperScanHost(scanFile: selected.url)`만 넘기고, 이미 있는 `selected.label`은 헤더에 안 씀
- `QualityScanPdf`는 `url`만 있고 `fileName` 없음
- `ReportSetDetail`도 `pdfUrl`만 있음

## 바꿀 것
1. `ReportSetDetail`에 `pdfFileName` 추가. `remote_report_set_repository.dart`의 split asset `getAsset`에서 `contentUrl`과 함께 `asset.fileName`을 채운다.
2. `QualityScanPdf`에 `fileName` 추가. `quality_issue_view_model.dart` `_loadReportPdfs`에서 `detail.pdfFileName`을 넣는다.
3. `PaperScanHost`에 optional `displayName` 추가. 비어 있지 않으면 그걸 쓰고, 비면 기존 `paperScanDisplayName(scanFile)` fallback. demo용 hardcode 매핑은 유지.
4. `quality_media_host.dart`
   - `_MediaEntry` / 스트립: report는 `pdf.fileName`(비면 `성적서`), jobMedia는 기존 `item.label`
   - `PaperScanHost` 호출부에 `displayName: selected.label` (및 `_ReportPdfView`는 `pdf.fileName`) 전달
5. 범위 밖: `QualityVideoHost`는 이번 요청에서 건드리지 않음

## 유지할 것
- PDF 로딩은 계속 `scanFile`/`url` (content URL)
- seek·탭 선택·뷰포트 높이 등 UI 동작
- `QualityJobMedia`의 `fileName` 매핑 경로

## 이번 작업에서 만들지 않음
- URL percent-decode만으로 끝내는 임시 처방(주 해결책이 아님)
- video 호스트 표시명 변경
- 새 추상 계층

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
