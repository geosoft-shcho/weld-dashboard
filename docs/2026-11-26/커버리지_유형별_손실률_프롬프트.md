# 커버리지 KPI 유형별 손실률

## 목표
커버리지 카드 아래 유형별 줄은 커버리지 %가 아니라 손실률만 보이게 하고, 유형/손실 색점·초록 강조를 없앤다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md`
3. `lib/src/presentation/features/collection_monitoring/widgets/collection_kpi_cards.dart`

## 현재 상태
- 종합 줄: `_coverageOverallLabel` → `"종합% (손실 M%)"`
- 유형별: `_DataTypeCoverageRichText`가 `coverageRatio×100`을 초록으로 표시
- 범례: `_CoverageLossLegend` + `_LegendSwatch`로 유형(초록)/손실(빨강) 점

## 바꿀 것
1. `_DataTypeCoverageRichText`: 유형명 + 손실률 `(1−coverageRatio)×100` (소수 1자리 `%`). `coverageRatio == null`이면 `—`
2. 유형별 값에서 `STATUS_OK` 등 색 강조 제거 — 본문과 같은 `_secondaryValueStyle` 계열
3. `_CoverageLossLegend` / `_LegendSwatch` 색점 제거. secondaryLabel은 `손실` 또는 `유형별 손실` 텍스트만
4. 본 프롬프트 범위에서 `collection_kpi_cards.dart`만 수정

## 유지할 것
- 종합 줄 `"N% (손실 M%)"` (`_coverageOverallLabel`)
- KPI 네 장 구성·카드 선택·작업량·수집량·임베딩
