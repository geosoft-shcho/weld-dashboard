## 현재 상태
- `TimelineViewKind`: `timeline` | `roadmap`, `resolveTimelineViewKind`는 선택값 그대로 반환
- host `_BoardView`: viewKind로 `CollectionRoadmapView` / `CollectionTimelineBoardView` 분기
- host `_doesShowDrillCrumbs`: timeline만 true, roadmap은 false
- 툴바: `_ViewButton` 「타임라인」「로드맵」 → `didSelectTimelineView`
- query/present: `viewKind`를 보드 `CollectionTimeline.viewKind`에 넣음
- 로드맵 전용: `collection_roadmap_view.dart`, `collection_roadmap_layout.dart`, `test/collection_roadmap_layout_test.dart`

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
