# 타임라인 보드 빈 상태 UI

## 목표
`ListCollectionNodes` 결과가 없어 `timeline.resources`가 비면, 큰 보드 영역에 문구만 깔리지 않게 하고 패널 중앙에 짧은 안내만 보이게 한다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md`
3. `lib/src/presentation/features/collection_monitoring/widgets/collection_timeline_board_view.dart`
4. 계약·화면안: 없음

## 현재 상태
- `resources.isEmpty` → `_EmptyBoardBody`
- fallback은 `Padding` + `Text(_fallbackLabel())`라 Expanded 패널 전체가 비고 좌상단 텍스트만 남음

## 바꿀 것
1. `_EmptyBoardBody` fallback(및 단순 문구 분기)을 `Center` + `ConstrainedBox`(maxWidth ~360)로 가운데 정렬
2. 제목(`_fallbackLabel`) + 보조 한 줄 — 전체 면적을 텍스트로 채우지 않음
3. `jobDayEmptyHint` 상세 Column도 같은 중앙 정렬로 맞춤
4. 본 프롬프트 저장 후 이 파일만 수정

## 유지할 것
- 문구 내용(`_fallbackLabel` depth 분기, hint 분기·점프 버튼)
- 리소스가 있을 때 타임라인 보드 본문

## 이번 작업에서 만들지 않음
- neon_timeline 빈 축 가짜 행
- KPI·조회 API 변경

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
