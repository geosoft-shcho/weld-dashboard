# 타임라인 상단 한 줄 UI

## 목표
툴바(줌)와 드릴 크럼·범례를 한 Row로 모아, 상단 크롬을 한 줄로 표시한다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md`
3. `lib/src/presentation/features/collection_monitoring/widgets/collection_timeline_host.dart`
4. 계약·화면안: 없음

## 현재 상태
- host Column: 1줄 `_Toolbar`(줌), 2줄 `_DrillCrumbs` + `_Legend`
- 뷰 전환 버튼은 없음(줌 ComboBox만)

## 바꿀 것
1. 권장 배치로 한 Row: `[Expanded(_DrillCrumbs)] · [_Legend] · [줌 ComboBox]`
2. 분리된 `_Toolbar` Padding 제거. 줌 UI는 같은 Row 오른쪽(또는 `_Toolbar`를 Row 자식으로만 유지)
3. 상단 Padding은 한 블록으로 유지(top/bottom 8)

## 유지할 것
- 드릴 크럼·범례·줌 동작, 보드·인스펙터 레이아웃

## 이번 작업에서 만들지 않음
- 줌 옵션·보드 본문 변경
- 새 디자인 시스템

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
