# 셸 설정 그룹 · 내정보 다이얼로그

## 목표
사이드 NavigationPane에 「설정」 그룹을 두고 내정보·비밀번호 변경·로그아웃을 연다. 타이틀바의 비밀번호 변경·로그아웃 버튼은 없앤다. 내정보는 현재 로그인 계정 다이얼로그로 보여 준다.

## 먼저 읽을 것
1. `shell_screen.dart` — `_buildPaneGroupLabel`, `_AuthSessionActions`, `_ChangePasswordDialog`
2. `app_coordinator.dart` — pane 인덱스 상수(계정 8·9·10). `PaneItem`만 번호에 들어감
3. `auth_user.dart` — 내정보 표시 필드

## 현재 상태
- 타이틀바 `_AuthSessionActions`에 표시 이름 + 비밀번호 변경·로그아웃 버튼
- 비밀번호 변경은 같은 파일의 `_ChangePasswordDialog`
- pane에 「설정」 그룹 없음. fluent_ui `PaneItemAction`은 `effectiveItems`에서 제외되어 선택 인덱스를 밀지 않음

## 바꿀 것
1. `shell_screen.dart` `NavigationPane.items` 맨 끝(계정 그룹 다음, 없으면 관리 다음)에:
   - `_buildPaneGroupLabel('설정')`
   - `PaneItemAction` 3개: 내정보 · 비밀번호 변경 · 로그아웃
   - 아이콘·툴팁은 기존 `_navPaneItem`과 같은 compact 툴팁 패턴
   - `body`는 `SizedBox.shrink()`(Action 기본값)
   - onTap: 내정보 → `_MyAccountInfoDialog` / 비밀번호 → 기존 `_ChangePasswordDialog` / 로그아웃 → `AuthSessionViewModel.signOut()` (`isBusy`면 no-op)
2. `_AuthSessionActions`: 비밀번호 변경·로그아웃 버튼·관련 `SizedBox` 제거. 표시 이름 `Text`만 유지
3. `_MyAccountInfoDialog`(`ContentDialog`) 추가 — `AuthSessionViewModel.user` 기준:
   - 로그인 아이디(`loginName`)
   - 표시 이름(`displayName`, 비면 안내)
   - 역할(`roleName`, 있으면 `roleId`)
   - 권한 목록(`permissions`, 줄바꿈 또는 쉼표)
   - 확인 버튼만으로 닫기
4. 작업 프롬프트 본 문서 저장 후 구현

## 유지할 것
- `_ChangePasswordDialog` 동작·문구
- `AppCoordinator` pane 인덱스·라우트(설정 Action은 인덱스에 안 넣음)
- 타이틀바 최신 업데이트 시각, 표시 이름

## 이번 작업에서 만들지 않음
- 계정 편집·역할 변경·GetCurrentAccount 재호출
- 설정용 라우트·별도 화면 body
- 계정/역할/토큰 관리 메뉴 변경

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
