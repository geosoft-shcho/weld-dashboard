# 하루 타임라인 뷰 제거

## 목표
「하루 타임라인」 버튼과 `CollectionDayTimelineView`를 없앤다. `TimelineViewKind.day`로 가던 경로(자동 전환 포함)는 리소스 뷰로 맞춘다.

## 바꿀 것
1. 삭제: `collection_day_timeline_view.dart`
2. `collection_timeline_host.dart`: day 버튼·import·분기 제거
3. `TimelineViewKind`: `day` 제거
4. `CollectionTimeline`: `canShowDayView` 제거
5. present/query use case: day 경로 제거, 장비 1대여도 resource
6. VM: `didTapOpenDayView` 제거
7. 테스트: day 기대 → resource로 수정
8. 본 프롬프트 저장 후 구현

## 유지할 것
- 리소스·로드맵 뷰, 줌, 드릴 크럼(리소스)

## 이번 작업에서 만들지 않음
- 새 일별 뷰 대체 UI
- neon_timeline 패키지 수정

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
