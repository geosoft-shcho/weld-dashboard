# 적재 탭 건수 제거

## 목표
「적재 파이프라인」탭 라벨에 실패·진행 건수를 붙이지 않고 탭 텍스트만 보이게 한다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md`
3. `lib/src/presentation/features/collection_monitoring/collection_monitoring_screen.dart`

## 현재 상태
- `_pipelineTabLabel(pipeline)`이 `failedCount`/`runningCount`로 `· 실패 N` / `· 진행 N`을 붙인다

## 바꿀 것
1. 탭 라벨을 `'적재 파이프라인'` 고정 문자열로 둔다
2. `_pipelineTabLabel`이 더 이상 쓰이지 않으면 제거한다

## 유지할 것
- 파이프라인 탭 본문 칩의 실패·진행 건수
- 탭 전환·ListTraces 조회

## 이번 작업에서 만들지 않음
- Summary `trace_*_count` 정리
- 칩 UI 변경

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
