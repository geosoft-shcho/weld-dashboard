[mediatag] proto 변경 ② 만들기·고치기·지우기와 업로드가 추가됐습니다

기존 화면에는 영향이 없는 새 기능입니다. ①과 같은 proto에 들어 있습니다.

WorkService에 공사, 작업, 패스, 작업자, 장비의 Create·Update·Delete와 품목 배정(CreateProjectItems, UpdateProjectItem, ListItems)이 생겼습니다. ID는 서버가 매기고, 고치기는 update_mask에 넣은 칸만 바뀌며, 쓰이고 있는 것을 지우면 FailedPrecondition입니다.

파일 업로드는 POST /assets(multipart)입니다. metadata(JSON: jobId, passId, equipmentId, timeOrigin) 파트 다음에 file 파트를 보냅니다. 종류는 서버가 파일 내용으로 정하고, 영상·음성·센서 같은 시간 자료에는 timeOrigin이 필수입니다. 응답의 runId로 ToolService.GetRun을 불러 후처리가 끝난 뒤 타임라인을 다시 불러오세요. 받는 형식은 AssetService.ListUploadFormats로 조회합니다.

자세한 내용은 첨부의 "공사·작업·패스 관리와 업로드 안내.md"에 있습니다.
