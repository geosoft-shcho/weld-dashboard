# 에셋 첨부 다이얼로그 목록 선택

## 목표
작업 상세·첨부 탭과 멀티모달·에셋 패널의 「에셋 첨부」에서 번호 입력을 없애고, 검색어를 넣었을 때만 ListAssets로 후보를 불러 선택한 뒤 AttachAsset한다. 미첨부만 필터는 기본 OFF다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `.cursor/skills/apply-guidelines/SKILL.md`
3. `lib/src/presentation/features/job_lookup/widgets/job_attachment_tab.dart` `_didTapAttach`
4. `lib/src/presentation/features/video_multimodal/widgets/assets_side_body.dart` `_didTapAttach`
5. `ListAssetLookupPageUseCase` / `ListAssetsRequest` (`query`, `unattached_only`, `page_size`)
6. `lib/src/presentation/features/asset_lookup/asset_upload_dialog.dart` (다이얼로그 배치 참고)

## 현재 상태
- 두 화면 모두 에셋 번호 TextField + 패스 Combo → AttachAsset
- ListAssets는 에셋 조회·작업 첨부 목록에 이미 쓰임

## 바꿀 것
1. 번호 입력 제거. 검색어(`query`)·종류·미첨부만(기본 OFF)·페이지로 후보를 고르는 UI로 교체
2. 종류를 먼저 고르면 목록을 로드한다. 검색어는 선택이며 좁히기에 쓴다.
3. 종류·검색이 모두 비면 ListAssets를 호출하지 않는다. page_size 50 + 다음 페이지
4. 패스 선택 유지. 목록은 다중 체크. 선택 assetIds를 AttachAsset 순차 호출(배치 RPC 없음)
5. 공통 다이얼로그 위젯 1개(`asset_lookup` 기능 폴더). 새 UseCase·상태관리 금지
6. 이 작업에 이미 첨부된 id는 목록에서 제외하거나 선택 불가

## 유지할 것
- AttachAsset / 패스·작업 공용 / 첨부 후 목록 갱신
- 문서 PDF 안내 문구
- 버튼명 「에셋 첨부」

## 이번 작업에서 만들지 않음
- 에셋 업로드 플로우 변경
- job/project 등 AssetJobFilter 전체
- 에셋 조회 화면 리팩터

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
