# 파일 목록 업로드 시각 열

## 목표
파일 관리 목록 행에 **업로드(적재) 시각**을 보여 준다. proto `Asset.collected_at`(저장소에 들어온 시각)을 쓴다. `recorded_at`은 기록 시작이라 쓰지 않는다.

## 먼저 읽을 것
1. `README.md` 목적 절
2. `protos/mediatag/asset/v1/asset.proto` collected_at / recorded_at
3. `lib/src/domain/entities/asset_lookup_row.dart`
4. `lib/src/data/repositories/remote_asset_lookup_repository.dart` `_rowFrom`
5. `lib/src/presentation/features/asset_lookup/asset_lookup_screen.dart`
6. `DashboardFormatters.dateTime`

## 현재 상태
- `AssetLookupRow`에 `recordedAt`만 있고 `collectedAt` 없음.
- 목록 헤더: 번호·종류·파일·장비·크기·길이·상태 (+체크·동작).

## 바꿀 것
1. `AssetLookupRow`에 `DateTime? collectedAt` 추가.
2. `_rowFrom`에서 `asset.hasCollectedAt()`이면 local `DateTime`으로 매핑.
3. 목록에 열 **업로드** 추가(크기 앞 또는 상태 앞). 값은 `DashboardFormatters.dateTime`, 없으면 `—`. columnFlexes 조정.

## 유지할 것
- recordedAt·상세 화면·삭제·체크박스
- 다른 CatalogLookupTable 화면

## 이번 작업에서 만들지 않음
- recorded_at 열, 정렬·필터 by collected_at, 상세 화면 변경

## 복잡한 코드 제거 및 금지
- 한 화면·한 동작을 위해 새 추상 계층, 전략, 팩토리, 제네릭 헬퍼를 만들지 않는다.
- 같은 역할의 위젯, ViewModel, UseCase, 화면 흐름이 있으면 그것을 쓴다.
- 이번 변경으로 쓰이지 않게 된 분기, 플래그, 래퍼, 죽은 코드는 제거한다.
- 조건 중첩과 모드 플래그 조합으로 경우를 늘리지 않는다.
- 호출을 한 겹 감싸기 위한 파일은 만들지 않는다. 파일 분리는 책임이 분명할 때만 한다.
- 새 상태관리, 새 디자인 시스템, 카드 UI를 도입하지 않는다.
- 프롬프트 범위 밖의 리팩터, 이름 정리, 스타일 통일을 끼워 넣지 않는다.
